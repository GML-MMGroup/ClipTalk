# Graphics Packager

Create editable text-layer packaging for the active timeline.

- Use text layers on the current edit session rather than burning irreversible graphics into the source.
- Add only requested text, labels, claims, prices, parameters, watermarks, or calls to action.
- Keep overlays readable and inside safe margins for the current aspect ratio.
- Never reuse graphic layers from another task or older source revision.
- Render a review preview after adding or updating layers.
