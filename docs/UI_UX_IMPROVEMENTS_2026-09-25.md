# 用户体验改进与验收记录（2026-09-25）

本轮基于现有任务、成片预览、片段回看、移动端审核和设置流程实施改进，保留现有绿色主题、字体、工作区结构和导出校验规则。

## 问题、实施方案与结果

| 优先级 | 用户遇到的问题 | 已实施的改进 | 验收重点 |
| --- | --- | --- | --- |
| P0 | 不同失败都被解释为“没有匹配内容”，恢复建议失真 | 根据终止步骤区分缺少基础成片、其他前置条件不足、封面不匹配、确实没有候选内容、执行失败和未知原因；历史计划在读取时补充解释，不改写保存记录 | 缺少基础成片显示补充要求入口；未知原因不编造检索建议 |
| P0 | 终止计划的恢复按钮被隐藏，用户无法继续 | 仅在确实有固定操作栏的状态隐藏重复按钮；失败和无结果卡片保留恢复操作 | 恢复入口可见；补充要求保留已有草稿，不自动提交 |
| P0 | “已生成”容易被理解为质量检查通过 | 分离生成状态和版本质量状态，检查提示绑定对应成片；缺少报告时明确说明限制 | 切换版本不串用检查结果；未检查不显示通过；保留原有导出限制 |
| P1 | 正式成片下载入口藏得过深 | 顶部、对话结果和当前版本区提供直接下载入口；结果入口标明版本、格式和尺寸 | 桌面与移动端均可找到下载；使用已有下载及校验路径 |
| P1 | 短片段时间精度不足、片段名称缺乏意义、回看后难以返回成片 | 片段范围显示到百分之一秒并说明时长；优先使用具体标题或文本；无效时间禁止跳转；回看源片后提供“返回 V1”等入口 | 亚秒范围可辨识；无效时间不会错误跳转；返回原成片文件 |
| P1 | 更多菜单 SVG 尺寸失控 | 统一菜单图标尺寸、描边和主题颜色 | 菜单没有巨大黑色图形；键盘关闭后焦点恢复 |
| P1 | 任务名称难辨识，搜索不容易找到目标 | 优先显示自定义名称和任务目标，保留文件名回退；重名附加时间与标识；搜索覆盖目标及本机自定义名称，丢弃过期搜索响应 | 新旧任务兼容；自定义名称可搜索；快速切换搜索不被旧响应覆盖 |
| P1 | 小屏时间轴占据过多空间，审核操作层级不清晰 | 小屏默认收起时间轴，记住当前会话中的展开选择；把显示设置放入独立菜单；审核区先展示当前版本和下载，再展示采用片段；低频操作收进“更多操作” | 展开与收起有效；桌面布局保留；跨断点和主题切换不溢出 |
| P2 | 首次使用不清楚先做什么，设置名称偏技术化 | 添加简短操作顺序与素材就绪提示；设置页使用“画面分析”“理解剪辑要求”“执行剪辑”“本地能力”等名称；短屏压缩辅助说明 | 素材状态与提示一致；640×400 窗口仍能使用输入区 |

## 实现范围

- 后端：`app/job_projection.py`、`app/agent_platform.py`、`app/agent_api.py`、`app/main.py`，负责终止原因、历史记录只读投影、目标字段和搜索。
- 前端：`static/ui-copy.js`、`static/app-shell.js`、`static/app.js`、`static/agent-workspace.js`、`static/workspace-controller.js`、`static/index.html` 及工作区样式，负责共享文案、恢复入口、版本操作、时间轴和响应式布局。
- 回归：新增 `tests/test_ux_recovery.py` 与 `tests/frontend/ux-review.test.mjs`，并更新受本轮交互变化影响的现有用例。

没有新增运行依赖，没有执行安装或部署，没有修改模型配置、真实任务记录、上传素材和输出文件。

## 生效范围与剩余限制

现有服务仍运行于 `http://127.0.0.1:5191`，本轮没有重启服务。静态资源版本号已更新，刷新页面可加载前端修改；后端终止原因投影和任务搜索改进需要服务重新加载代码后生效。

历史记录若没有保存具体检查报告，界面只能如实提示报告缺失并建议人工核对，不能补造质量结论。本轮验证覆盖交互与状态解释，不代表重新验证了真实视频生成算法的质量。
