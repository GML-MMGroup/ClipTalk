# 新建任务入口与 Agent 工作台

## 当前设计（2026-09-21）

按用户要求恢复“左侧 AI 对话、右侧视频工作区”。新建任务右侧显示上传入口；上传完成后直接进入可播放的源视频预览。手机使用原有的助手／预览切换。保留现有字体与森林绿主题，不添加装饰插画、假进度或重复状态。

左侧准备区靠底部排列：轻提示“你想怎么剪？”、三个文字示例、原聊天输入框。移除重复的解释句与执行设置标签，按钮仅显示当前执行方式（仍保留无障碍名称）。上传前后保持双行输入和底部位置，键盘提示一致；中间空间留给后续对话。短屏缩减标题区间距，不压缩输入功能。

- 选择或拖入一个有效视频即开始上传，创建待输入要求的任务草稿，不提交剪辑要求。
- 可以提前写要求或点击示例；素材未上传完成时发送按钮不可用。上传期间继续修改的文字也会保留。
- 上传成功后可以播放、暂停和拖动源视频进度，随后用户手动发送要求；保持原聊天框 Enter 发送、Shift+Enter 换行的操作。
- 上传进度来自实际回调；失败保留要求和文件，提供“重新上传”，防止重复请求。
- 单纯上传与预览不要求配置 AI 模型；真正发送剪辑要求时由原有 Agent 流程检查配置。
- 默认自动执行，可选分步审核；保留原执行方式与技能选择。Agent 提交失败恢复要求，重试沿用同一个任务。
- 复用原上传入口和聊天输入框，不移动、不克隆输入框；新任务隔离令牌继续阻止旧响应覆盖当前任务。

## 实现边界

### 成片质检与要求落实（2026-09-22）

- 修复“竖屏产品宣传短片 + 封面”被误判为仅封面画幅的情况。新计划保留视频画幅转换步骤，并向最终交付检查传入目标视频画幅与封面文字；封面尺寸不再代替视频画幅。
- 可见对象类条件继续逐帧检查；语义／事件类按整段画面结合有来源的对白上下文检查，不要求每张画面或每个片段重复所有目标。源对白仅用于上下文，不宣称已经复听成片音轨。
- 语义任务在片段抽检后增加一次整条内容目标覆盖检查，以完整原始查询为准逐项记录，防止只检查已解析条件中的前半句。保留抽样性质与现有片段预算，不声称完整逐帧验收。
- 保留不同查询条件，不再仅因其涉及同一产品就合并成第一个视觉条件。模型提示明确区分并列内容目标与同一画面必须同时满足的条件。
- 记录实际输出版本、片段范围、抽样编号与时间、判断依据。模型不确定／缺失返回为“待复核”，服务或抽帧失败为“检查未完成”，明确不符为“需要修改”；缺失证据不能伪装成通过。
- 抽样图保留完整画面比例，不把竖屏画面裁成横屏来检查。不同来源的报告绑定各自受检版本；存在多个版本且报告没有绑定时不猜测定位目标。
- 对话直接展示精简质检结果，详细目标、执行过程保持折叠。合并重复记录与摘要，同文案但不同时间的片段仍分别保留入口；旧记录不补造缺失原因。定位按钮与说明分行，避免窄栏将正文挤成细条。
- “查看画面”定位后暂停，“检查片段”定位后播放；任务、方案或媒体源变化时不执行延迟定位。不提供无法兑现的自动修复承诺，非时长问题使用现有修改要求入口。
- 验证：412 项相关后端测试、33 项界面回归和 32 项 Agent 接口／布局检查通过；最后的说明合并和窄栏调整另重跑 2 项定向交互测试，静态与重复样式检查通过。人物目标澄清测试的通知写入已隔离到 mock，避免依赖本机可选识别能力。
- 真实页面仅作只读检查：旧样片两处定位准确，未发送 API 写请求、未启动模型或重新生成媒体。浅深色和窄屏截图均检查。静态界面已由服务提供；截至本次交付，后端进程尚未重启，等待用户确认。旧计划与旧横屏视频保持不变，需要重新规划生成才能得到竖屏成片。

### 计划确认入口（2026-09-22）

- 对话里的待确认计划仅通过顶部操作条“确认并开始”启动，计划卡片底部保留“修改计划”；详情抽屉和旧版回退界面仍有可用的确认操作。
- 启动请求使用同一份计划与校验值，所有确认入口共享锁；请求中显示“正在启动…”，失败恢复按钮并显示错误，切换任务后忽略旧响应。
- 对话流收到待确认计划但任务状态轮询尚未更新时，流程栏先显示“等待确认计划”，不继续宣称正在生成计划。
- 待确认计划中的视频、字幕、封面等未启动产物显示“待生成”；真正的失败与进行中状态仍单独显示。
- 手机对话页不再重复显示底部快捷操作条；在预览／审核页仍保留快捷入口。

### 执行中的进度与停止入口（2026-09-22）

- Agent 已返回执行计划时，只保留一张执行卡，隐藏同一任务的通用检索进度卡；独立检索仍保留原有进度与停止入口。
- 顶部使用“分析素材”“生成样片”等整体阶段，卡片使用“正在寻找适合开场的片段”等当前动作；工具名称、技术步骤保留在“查看处理详情”中。
- 耗时来自任务计时；数量和进度条仅在当前工具对应的实际操作提供确定进度时显示，不使用估算百分比填充进度条。
- 主界面只保留“停止任务”，调用整个计划的取消接口。请求中禁止重复点击，失败显示错误并允许重试，切换任务后不应用旧响应。
- 封面未开始时仅在“后续”摘要中显示，不提前展示空封面卡；进入封面步骤后恢复封面状态。过期的“请核对后开始执行”通知折叠为处理记录。
- 复用现有卡片与主题，不新增样式表；状态点的轻微动效遵循减少动态效果设置。

### 片段选择与核对（2026-09-22）

- 列表和候选抽屉均使用顶部原生“全选”复选框，支持未选、半选、全选及空格键。筛选时显示“全选当前结果”，只修改筛选内的选择，保留筛选外的已选片段；包含折叠结果，不包含已排除片段。
- 勾选只保存选择草稿，不调用批量保留或核对反馈接口；“已选用”和“范围已确认”独立显示。明确保存的空选择不再被默认勾选覆盖。
- 每项保留“播放”“核对片段／调整片段范围”“标记不相关”。核对区可在范围未改动时明确点击“已核对，保留”；改动范围时使用“保存范围并确认”。对象匹配状态不因范围确认被自动改写。
- Agent 证据审核只显示“保存选择并继续”，隐藏独立生成设置；存在待核对片段时显示数量和“查看下一段”。成功保存选择后恢复同一计划的同一步骤，不另行调用独立生成接口。
- 独立检索仍使用原生成流程、风险确认、字幕和排序设置，不统一强制所有片段必须核对；保留完整性与唯一起剪位置等原有约束。
- 保存或核对失败显示就地错误并可重试；批量选择保存失败恢复原勾选，提交期间阻止重复请求。继续计划时校验任务、计划、步骤和检索标识；过期范围／内容约定不能视为已确认。
- 缩略图、选择框、标题和操作按容器宽度排列；修正内容卡的浅色文字对比度，保留原主题。对话刷新时移除旧侧栏内同一检索的重复可编辑列表。
- 验证使用模拟接口，不修改真实任务、素材或模型配置。覆盖选择与核对分离、失败重试、防重复提交、筛选保留、空选择、范围过期及两种生成流程，并检查深浅色与窄屏截图。

### 上传与预览

- 移除独立准备页模块；上传与任务交接复用 static/app.js，布局状态由 workspace-controller.js 管理，新增样式归入 workbench.css。
- 不修改后端接口，不改变已有任务的时间轴、精剪、字幕和导出流程。
- 上传成功不等于分析完成。进入工作台后继续使用公开任务状态、执行步骤与真实方案卡片；不生成假耗时、假候选数量。
- 真实服务验证只读；上传、失败重试和模型提交使用测试接口，不触碰实际任务数据。

## 设计沿革

此前尝试过流程节点、准备状态和合并上传与要求的独立表单。用户明确要求恢复之前能播放视频的工作台，因此当前恢复分栏，并将“上传预览”与“发送要求开始剪辑”分开；不再使用准备完成后统一上传并自动发送的流程。功能测试之外仍须检查实际整页截图。
