## 已实施

| 问题 | 修改及行为 |
| --- | --- |
| 切换任务后，旧规划响应覆盖新任务计划、草稿或按钮状态 | Agent 工作区增加任务身份、视图代次和 AbortController；迟到的成功及错误响应均不能写入其他任务。 |
| 取消后，同步结果、Future 或人工确认请求恢复执行状态 | 提交结果时核对计划状态、步骤尝试次数及操作 ID；取消同步更新 run；迟到操作调用取消回调，不再注册。 |
| 被取代的规划请求仍提交计划 | 持锁校验 planningRequestId，过期请求不能落库或更新当前工作区。 |
| 轮询一次失败即停止，事件恢复不完整 | 增加连接状态提示与退避重试；订阅 preview.ready；重连补读当前快照；后端支持 Last-Event-ID 游标。 |
| Esc 退出认证后无法重新验证 | 对话框关闭统一结束 Promise，清理事件监听，并防止旧 close 事件关闭新请求。 |
| “只保留 Speaker 2，不要主持人提问”反向排除目标人物 | 分离肯定要求和排除条款；保留 Speaker 2，将主持人提问作为排除要求传入检索。 |
| “最后两分钟”被当作成片时长 | 区分素材范围与目标时长；规划工具及衍生任务传递真实起止时间；缺失尾部范围所需时长时明确拒绝。 |
| “加中文字幕”漏掉字幕、误开文字包装 | 修正字幕语言匹配及字幕/文字包装区分，保留否定要求。 |
| “做三版，每版30秒，不要复用片段”退化为一版 | 识别简短中文版本数；传递不复用要求；应用前检查版本数量、跨版本源片段重叠和安全方案数量，不满足时返回明确无结果原因。 |
| 工具数值范围约束未生效 | 校验 enum、上下界、非有限数值及源片段结束时间大于开始时间。 |
| 已取消、已转入后续任务显示成未完成或普通完成 | 独立 cancelled / handed_off 展示状态；运行中的计划不被旧样片状态覆盖。 |
| 伪阶段百分比、未知进度显示为 0% | 规划展示真实阶段及耗时；无法测量的进度采用不定进度提示；移除服务端凭时间轮换的虚构规划活动。 |
| 语音或规划服务异常仍显示正常；两个模块抢写状态 | 汇总媒体、语音、模型与 Agent 健康情况；侧栏服务状态由 app-shell 单独负责，设置面板仍展示细项。 |
| 新建页首屏保留隐藏侧栏宽度、输入框下缘被裁切 | 修正新建/编辑网格选择器及 min-height；紧凑导航在首页保持隐藏；上传区域列宽允许收缩。 |
| 首页卡片文字低对比、主按钮出现不同主题强调色 | 统一 ct / ct4 / pw 核心颜色；修正嵌套首页任务行的样式命中；下载和导出沿用浅绿色主操作色。 |
| 计划按钮与计数溢出、播放器顶部标题与操作挤压 | 计划操作允许换行，计数独占一行；标题和版本选择器允许收缩，窄宽度隐藏重复状态文字。 |
| 导出先被接受、随后才报原视频字幕状态未确认 | 请求入口提前校验字幕草稿与原字幕确认状态，返回可操作的 409 提示，避免启动注定失败的渲染。 |

### 真实视频链路

独立实例 `127.0.0.1:5299`，独立数据目录 `/tmp/cliptalk-audit-e2e/data`；没有操作原服务任务。

1. 从项目现有视频生成 18 秒、640×360 的测试素材，使用浏览器真实上传。
2. 输入“生成一条约8秒的高光，加字幕，保持原比例”。使用当前实际模型配置生成计划。
3. 确认计划，执行素材检查、高光分析、时间线提案及应用、字幕生成和审核样片渲染。
4. 得到 8 秒、字幕烧录的审核样片，计划进入 preview_ready。
5. 首次正式导出暴露字幕状态确认检查过晚的问题，已据此补上入口检查与回归测试。
6. 模拟人工确认原视频字幕状态，更新字幕草稿、重新生成匹配的精确预览，再正式导出。
7. 正式成片下载 HTTP 200，文件 865733 字节；ffprobe 验证视频 640×360、包含音轨、时长精确为 8 秒。
