# 界面状态与操作说明优化计划

范围：修复本轮确认的 8 类误导问题。只调整前端交互与说明，不改动已有视频、任务数据、生成算法或 app/main.py。

## 修改与验收

1. 预览：源视频按片段播放明确称为“快速预览”；单独提供“审核样片”入口，只有最新样片可播放。样片播放状态与文件就绪状态分开表达。验证源片、快速预览、样片之间切换及过期状态。
2. 字幕关闭：显示“不额外添加字幕”，说明源视频自带字幕不会移除；不再提示必须校对。
3. 字幕保存：根据服务端返回的草稿/人工确认/自动校对状态反馈。过期任务的响应不能更新当前页面。
4. 名称与保存：字段改为“本次导出名称”，明确生成时使用；进入不同草稿重置该字段，保存状态限定为剪辑草稿。
5. 封面：图片保存不等于视频绑定或片头渲染；仅有实际绑定记录才提示已关联，片头以生成结果为准。
6. 清晰度：去掉未依据分辨率判断的“高清”描述，改为正式成片/MP4；下载说明展示可用的真实分辨率。
7. 数量：无数量选择的自动高光入口不承诺多个版本；有版本数选择的入口按所选数量说明。
8. 导出：三个正式导出入口均说明生成完成后需下载；提交成功不提示文件已下载。正式文件入口统一为“下载 MP4”。

## 验证

- 针对上述状态增加回归测试，运行前端检查与相关浏览器测试。
- 在运行中的页面检查预览切换、字幕关闭和导出名称；不提交生成、删除、清理等真实任务操作。
- 更新静态资源版本，避免旧缓存；记录未验证项，不把界面验证描述为完整渲染验证。

## 执行结果

以上 8 项已实施。额外修正了预览标签在浅色模式下的对比度；未启用新增字幕时隐藏无效的拖动说明和编辑控件。

- 前端代码检查、完整前端回归通过；最后的局部调整再次通过相关测试。
- 新增 11 项状态测试及 1 项浏览器交互测试，覆盖字幕返回状态、迟到响应、封面绑定、真实分辨率、导出说明、样片过期与预览切换。
- 运行中的页面确认已有审核样片可直接加载（60.87 秒），快速预览与样片入口状态正确；验证过程中没有提交任务写入请求。
- 浅色/深色预览标签对比度分别约为 15.05/12.36；390px 宽度下三个预览入口均可见。
- 未执行真实视频重新生成、导出、封面绑定或工程清理；本轮验证侧重前端状态、交互及导出请求，不代表完整视频渲染验收。
