# 界面与操作流程修复记录

本轮以现有界面为基础，修复可读性、操作路径和状态反馈，不改动 `app/main.py`，不改写已有任务、素材和输出。

## 已落实的修复

| 范围 | 本轮调整 |
| --- | --- |
| 浅色模式 | 字幕窗口使用统一主题颜色；调深封面状态、历史记录和播放器按钮文字；保留视频画面本身的颜色。 |
| 页面布局 | 封面编辑区完整展开，隐藏无关时间线；修复手机标签栏与标题重叠，给底部操作栏预留位置。 |
| 字幕校对 | 使用源视频核对，支持本句试听、暂停和循环；按原片时间定位，无法可靠对应时禁用试听。 |
| 字幕编辑 | 支持撤销和多条成片切换；保留各条字幕的修改；未保存关闭时提供保存退出、放弃和继续编辑。 |
| 字幕确认 | 保存草稿不等于确认；确认条件未满足时保持禁用；按入口分别显示返回编辑、继续生成等下一步。 |
| 封面调整 | 可单独修改取帧时间、人物或主体、标题和比例；只重做封面相关步骤，保留已完成的视频分析、剪辑与字幕步骤。 |
| 失败恢复 | 字幕保存、封面生成与片头生成失败时保留可见说明；防止切换任务后，旧请求修改新任务界面。 |
| 预览与下一步 | 恢复任务时优先展示本次样片，不自动播放；尊重用户已选视频；手机端与桌面端共享当前待办动作。 |
| 文案 | 折叠历史方案和较长说明；精简空列表与重复入口；在方案详情中列出本次涉及的视频、字幕、封面和片头状态。 |

## 验证情况

- 前端全套测试：272 项通过。
- 后端相关测试：150 项通过。
- 前端、Python、页面资源归属与 CSS 检查通过。
- 覆盖桌面、平板和手机宽度，以及浅色、深色主题。
- 用独立生成的带声音测试视频验证了字幕定位、非静音播放、句尾暂停和循环；未使用真实任务生成新成片。
- 浅色文字抽查中，精剪页 96 个、封面页 62 个、设置页 37 个、手机预览页 21 个已测元素均通过。图片和渐变背景不能由这项检查可靠判定，因此不能据此宣称所有页面的每个元素均无问题。

## 生效与验证边界

前端刷新页面后可查看。封面局部重做涉及 Python 后端，需要在合适时间重启现有服务；本轮没有重启服务或中断已有任务。

自动化流程主要使用隔离的模拟接口，已有任务仅作只读观察。尚未进行付费模型调用或完整的真实素材生成验收。外部人物照片需要先有可用素材；本轮没有新增外部图片获取能力。
