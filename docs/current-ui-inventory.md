# ClipTalk 现有界面完整盘点

生成日期：2026-09-05  
用途：把当前 ClipTalk Web 工作台交给另一个 AI 重新设计时，作为现状描述、功能清单与交互约束。  
范围：记录当前界面、动态状态、面板、按钮、输入、时间线、弹窗和主要交互。不包含后端算法实现细节，除非该细节会影响 UI 状态。

## 1. 产品定位与总体界面目标

ClipTalk 是一个对话式 AI 视频剪辑工作台。用户上传视频后，可以直接输入剪辑要求，也可以选择快速模式；系统先生成计划或分析结果，再让用户审核、选择、合成、精剪、导出。

当前界面是一个专业工作台，不是营销页。核心任务是围绕“视频预览 + 对话指令 + 证据/候选审核 + 时间线调整 + 输出版本管理”完成视频剪辑。

必须保留的产品能力：

- 上传视频，创建剪辑任务。
- 对话式输入剪辑要求。
- 上传后显示 4 个快速模式：高光剪辑、内容探索、按人物剪辑、按说话人剪辑。
- Agent 自动选择 Skill、生成执行计划、等待确认后再执行。
- 视频预览、播放控制、源视频/成片版本切换。
- 高光事件、源镜头候选、内容匹配片段、人物轨迹、说话人轨迹审核。
- 主时间线、封面片头时间线、二次精剪时间线。
- 成片版本 V1/V2/V3 等多版本预览、下载和精剪。
- 字幕校对、封面确认、发布包/成片库管理。
- 设置模型、API Key、运行环境、Skills / Plugins。

不可随意替换的品牌约束：

- ClipTalk / 剪辑助理图标不能替换。
- 现有核心工作流入口不能删除，只能重组、降噪或换表现形式。
- 上传后既要支持“直接输入要求”，也要支持“点选快速模式”。

## 2. 当前视觉系统

当前是深色工作台风格。主要视觉 token 来自 `static/theme.css`：

- 页面底色：`#0a1014`，更深底色 `#080d11`。
- 左侧导航栏：`#0c1318`。
- 面板色：`#11191f`、`#18242b`、`#1e2b33`。
- 悬停面：`#26363e`。
- 线条：`rgba(193, 207, 213, .055/.10/.16)`。
- 主文字：`#eef2f3`。
- 正文：`#c7d0d4`。
- 次级文字：`#95a2a9`。
- 弱文字：`#707e85`。
- 主强调色：`#d6a15d`，hover 为 `#e3b572`。
- 成功色：`#7caf8d`。
- 警告色：`#d0a05b`。
- 危险色：`#c97d74`。
- 播放头色：`#d98c5d`。
- 字体：UI 使用 `Inter`, `Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`；展示字体使用 `VP Editorial Song`, `Noto Serif SC`, `Songti SC`。
- 控件圆角：6px；面板圆角：10px；特征面板圆角：12px。
- 全局 focus ring 是橙色 `#d6a15d`。
- 页面有非常弱的噪点背景覆盖层。

当前视觉问题：

- 暗色体系比较一致，但局部仍残留白色/浅色块，尤其时间线、候选、成片结果、部分按钮和播放器控制区域。
- 橙色在按钮、进度条、播放头、标签里同时出现，容易显得突兀。
- 很多面板依赖边框分割，线条密度高。
- 字号层级不稳定：有些标题过大，有些说明过浅，有些小字在深色背景中可读性不足。
- 左侧对话、右侧播放器、下方时间线之间视觉权重抢夺，主次不够清晰。
- 部分组件像“AI 生成的卡片堆叠”：边框、渐变、胶囊标签、过多状态文案同时出现。

## 3. 全局布局

当前页面由固定左侧 App Sidebar、中央工作区和多种抽屉/弹窗组成。

主结构：

- `appSidebar`：最左侧 72px 主导航栏。
- `workspace`：主工作区，首页时为 `home-mode`，进入任务后为剪辑工作台。
- `chat-panel`：任务中左侧剪辑助理对话区。
- `panel-resizer-left`：左侧对话区和右侧视频区之间的可拖拽分隔条。
- `review-panel`：右侧主视频审核区。
- `panel-resizer-right`：旧的右侧审核栏分隔条，部分布局中存在。
- `review-rail`：右侧/下方审核结果与成片结果区域，当前很多状态被整合进主工作区或对话区。
- 全局覆盖层：任务列表抽屉、候选抽屉、人物/说话人侧栏、设置页、二次精剪编辑器、字幕校对、确认弹窗、输入弹窗、Agent Registry。

桌面任务态布局：

- 左侧剪辑助理面板默认约 360-420px，可拖动调整。
- 中间有 8px 分隔区域。
- 右侧视频区占剩余宽度。
- 小屏时隐藏或收起部分侧栏和 resizer。

## 4. 左侧 App Sidebar

位置：页面最左侧，固定 72px 宽。

部件：

- 顶部品牌按钮：ClipTalk 图标，点击返回首页。
- `当前任务`：带图标、文字、当前状态小点；没有任务时 disabled。
- `新建`：创建新任务入口。
- `任务`：打开任务列表抽屉，带任务数量 badge。
- `成片`：进入成片库，带输出数量 badge。
- 底部工具区：
  - `检查服务`：查看服务状态，状态点显示服务是否正常。
  - `设置`：打开设置页面。

交互：

- 点击首页/当前任务/成片/设置切换 shell view。
- 点击任务打开 `sidebarHistoryDrawer`。
- 当前任务、任务数量、成片数量通过前端 catalog 刷新。

视觉问题：

- 72px 轨道清晰，但图标和文字同时存在时显得拥挤。
- 橙色高亮线、badge、状态点同时出现，注意力分散。
- “当前任务/任务/成片”垂直距离较近，信息密度偏高。

## 6. 首页 / 新建任务入口

挂载点：`homeView`。

内容：

- 标题区：`ClipTalk 工作台`，主标题 `开始一个剪辑任务`。
- 描述：上传素材，描述想保留的内容；生成前检查计划，生成后可继续调整。
- 统计区 `home-summary`：视频数、任务数、成片数。
- 创建入口 `home-create-surface`：创建剪辑任务，说明“选择视频并描述你想得到的结果”。
- 正在处理区：显示进行中或待确认任务。
- 空态：当前没有处理中的任务。
- 加载态：骨架卡。
- 错误态：最近任务暂时无法加载，带重新加载按钮。

交互：

- 点击创建任务进入上传界面。
- 点击正在处理任务卡打开任务。
- 首页任务卡与侧边栏任务列表共享状态来源。

视觉问题：

- 首页与任务工作台视觉语言不同，首页更像 dashboard，任务页更像剪辑软件。
- 创建入口如果过于卡片化，会和任务卡混淆。

## 7. 上传界面

挂载点：`uploadView`。

默认上传态：

- 左侧 intro：
  - 小标题：创建剪辑任务。
  - 大标题：上传素材，开始剪辑。
  - 描述：选择视频后，描述要保留的内容、人物、时长或风格；开始处理前可以检查完整计划。
- 右侧上传卡 `uploadForm`。
- 拖放区 `dropZone`：
  - 文件 input `videoInput`。
  - 加号图标 `drop-zone-add`。
  - 主文案：拖入视频，或点击选择。
  - 支持格式：MP4 / MOV / MKV / WebM / M4V / AVI。

本地预览态：

- `localPreviewPanel` 显示本地 `<video>`。
- 文案：源视频已就绪。
- 说明：描述目标并选择 Skill，先生成计划再执行。
- 按钮：更换视频。

任务设置态：

- `taskSetupView` 显示“设置剪辑任务”。
- `taskSetupPortal` 挂载上传后的 brief card。
- brief card 中包含：
  - 智能 Agent 任务说明。
  - 剪辑目标 textarea。
  - Skill 下拉。
  - 执行方式下拉：自动执行到审核样片 / 分步审核。
  - 管理 Skills 按钮。
  - 上传并生成计划按钮。
  - 快速模式 picker。
  - 素材范围选择：全片、开头、前半段、中段、后半段、结尾、自定义。
  - 自定义范围开始/结束输入。
  - 高光设置、内容检索设置、人物设置、说话人设置。
  - 意图澄清区。
  - 错误提示区。
  - 提交提示。

交互：

- 拖放或点击选择视频。
- 选择后建立素材工作区，但输入要求前不分析、不渲染。
- 更换视频会替换当前本地预览。
- 选择 Skill 和执行方式影响 Agent 后续规划。
- 素材范围选择自定义时显示开始/结束输入。

视觉问题：

- 上传界面右侧曾出现深色面板和左侧黑色空白不均衡。
- 上传引导和 Agent 设置可能同时存在，容易显得复杂。

## 8. 左侧剪辑助理对话区

挂载点：`chat-panel`。

固定结构：

- `panel-header`：
  - ClipTalk 剪辑助理图标。
  - 标题：剪辑助理。
  - 状态点 `directorDot` 和状态文字 `directorState`。
  - 收起按钮 `assistantPanelToggle`：显示 ‹ 和 “助手”。
  - 阶段流 `directorStageNav`：
    - 准备。
    - AI 分析。
    - 审核结果。
    - 生成成片。
- `directorTaskSummary`：
  - 当前任务摘要。
  - 任务模式 badge。
  - 当前阶段。
  - 文件名。
  - 状态说明。
  - 源视频时长、目标时长等事实。
  - 某些模式显示“说话人面板”或“人物面板”入口。

对话消息区：

- `chatMessages`。
- assistant 消息显示 AI/avatar、bubble、small 标题和正文。
- user 消息显示“你”。
- 支持 inherited history：从旧任务切换到新任务时出现“此前任务对话”折叠。
- 内容检索、成片结果、计划、brief 编辑器等会动态插入对话流。

上传后的草稿态：

- 系统消息：视频已上传并建立 Agent 素材工作区；输入前不会开始分析或渲染。
- 4 个快速模式卡片：
  - 高光剪辑：自动发现精彩事件，生成多个高光版本。
  - 内容探索：按动作、场景、对白或屏幕文字查找片段。
  - 按人物剪辑：识别出镜人物，提取目标人物相关画面。
  - 按说话人剪辑：区分不同声音，挑选指定说话人的发言。
- 标题：今天想创作什么？
- 提示：点选模式快速开始；也可在下方直接输入要求，Agent 会自动选择 Skill 并规划。

输入区：

- `chatForm`。
- `contentSelectionBasket`：内容成片清单，隐藏/显示。
- `chatContextBar`：引用当前画面或时间线状态。
- `quickWorkflowPicker`：点击快速剪辑后显示模式或启动设置。
- `chatInput`：描述剪辑要求。
- 工具栏：
  - Agent / Skill 菜单。
  - 快速剪辑按钮。
  - 更换或添加源视频 `+`。
  - 引用当前画面或时间线状态 `⌘`。
  - 让 Agent 自动优化指令 `✦`。
  - 发送按钮。
- 合成动作：
  - 字幕方式下拉。
  - 开始合成。
  - 按 AI 推荐事件合成。
  - AI 智能规划。
- 底部提示：Enter 发送，Shift+Enter 换行。

Agent / Skill 菜单：

- 本次使用的 Skill 下拉。
- 执行方式下拉。
- 管理 Skills / Plugins。

交互：

- 输入自然语言后提交给 Agent 或对应 workflow。
- 点击快速模式会进入对应启动设置。
- 选择高光可设置目标时长、版本数。
- 选择内容探索需要在输入框描述查找内容。
- 选择说话人可设置预计人数。
- 可引用当前时间线/画面状态作为上下文。
- 左侧面板可收起、可拖拽宽度。

视觉问题：

- 对话区承载了太多职责：消息、任务摘要、模式入口、Agent 计划、成片结果、输入工具。
- 小按钮和小字较多，弱文字在深色背景上对比不足。
- 当前快速模式卡如果过大显突兀，过小又像标签，尺寸需要平衡。

## 9. Agent 计划卡片与计划抽屉

挂载点：

- `agentPlanDock`：左侧对话区内的计划 dock。
- `agentPlanDrawerScrim`：抽屉遮罩。
- `agentPlanDrawer`：计划详情抽屉。

计划生成中状态：

- 顶部品牌：ClipTalk 图标、智能剪辑计划、剪辑助理、正在生成 Agent 执行计划。
- 右侧状态：构建中。
- 主标题：例如“规划关注 · 能力组合”。
- 计时：已用 xx 秒。
- 阶段轨道：
  - 目标。
  - 方法。
  - 范围。
  - 编排。
  - 校验。
- 当前关注提示：例如检查步骤边界、Skill 职责、不会读取视频内容。
- 底部：仅生成计划 · 尚未读取视频内容。
- 按钮：查看活动。

计划完成/待确认状态：

- 显示计划摘要、执行模式。
- 步骤列表：每步有标题、状态、预期输出、技术详情。
- 进度段 `agent-plan-segments`。
- 动作：
  - 查看全部步骤 / 查看计划。
  - 修改规划。
  - 确认并开始。
  - 停止计划。
  - 重新检索内容。
  - 重新执行失败链路。
  - 打开封面时间轴。
  - 选择并保存最终封面。
  - 打开审核样片或精剪时间线。

计划抽屉：

- Header：ClipTalk 图标、标题、关闭按钮。
- Tabs：计划 / 活动。
- 计划 tab：摘要、质检提示、封面审核、审核结果、步骤列表、技术详情。
- 活动 tab：时间线式事件记录；无记录时显示空态。
- Footer：当前计划可用动作。

交互：

- 点击查看活动打开抽屉并切到活动 tab。
- 点击计划 tab/活动 tab 切换内容。
- Esc 或关闭按钮收起。
- 修改规划显示 textarea，可提交生成修改方案。
- 确认计划后才开始调用分析/渲染工具。
- 停止计划进入取消状态。

视觉问题：

- 计划 dock 曾被放得过大，盖住视频区；现在应保持在左上/左侧，不应遮挡播放器。
- 当前风格多用进度线、边框、状态块，线条感强。

## 10. 右侧视频审核工作区

挂载点：`review-panel`、`reviewView`。

Header：

- 文件图标 `file-icon`。
- `reviewKicker`：源视频 / Vx · 高光成片等。
- `reviewTitle`：视频文件名。
- `reviewTaskMode`：任务模式 badge。
- `reviewStatus`：等待分析、已停止、完成等。
- `workspaceFlowMount`：任务流程进度，例如准备、高光发现、事件审核、生成版本。
- 右侧动作区：
  - 时长 chip。
  - 分辨率 chip。
  - `videoViewSelect`：源视频 / 成片版本选择。
  - 打开精剪时间线。
  - 确认并导出。
  - 保留成片。
  - 下载 MP4。
  - 更多菜单。

更多菜单：

- 横向布局 / 竖向布局。
- 下载封面。
- 下载发布包。
- 生成封面片头版。
- 下载字幕 SRT。

版本选择：

- `headerVersionPicker` 在播放器上方或 header 下方显示。
- 包含“预览”标签、源视频按钮、V001/V002/V003 等按钮。
- 点击切换播放器内容。

状态：

- 上传后源视频可预览。
- 任务分析中显示进度。
- 高光完成后可切换成片版本。
- 竖屏视频可切换竖向布局，有独立竖屏宽度 resizer。

视觉问题：

- Header 动作数量多，按钮和 select 容易形成工具条噪音。
- 橙色按钮在导出/下载/确认多个动作中重复出现，主次不稳定。

## 11. 播放器与播放控制

挂载点：`viewerShell`。

视频区域：

- `mediaFrame` 包含主视频 `mainVideo`。
- 左上角 `viewerBadge`：源视频、V3 样片、质量通过等。
- `playerNotice`：视频无法播放时显示。
  - loader。
  - 标题：视频暂时无法播放。
  - 错误详情。
  - 重新加载按钮。
- `outputEvidenceStrip`：当前成片依据，隐藏/显示。

播放控制：

- 主播放按钮 `playerPlay`。
- 上一段/下一段 `playerPrevious`、`playerNext`。
- 进度条 `playerSeek`。
- 时间 `playerClock`。
- 静音按钮 `playerMute`，包含扬声器、声波、静音斜线 SVG。
- 音量条 `playerVolume`。

## 31. 当前界面主要问题清单

视觉层级：

- 主任务是“看视频、选片段、生成结果”，但左侧消息、顶部状态、下方时间线、右侧候选经常同时抢注意力。
- 很多状态文案过长，造成界面像说明书，而不是剪辑工具。

线条密度：

- 面板边框、卡片边框、轨道线、分割线、progress line、details 分隔线都存在。
- 时间线尤其线条过多，导致用户难以判断哪些线条可交互。

颜色：

- 橙色承担了播放头、按钮、警告、强调、进度等多个角色。
- 局部白色/浅色残留破坏暗色统一。
- 弱文字过多，深色背景上可读性不足。

布局：

- 左侧对话区既是聊天、任务摘要、模式选择、Agent 计划、成片结果入口，负担过重。
- 视频播放器、时间线、成片版本之间有时出现大空白。
- 候选抽屉和审核区的关系不够明确。

字体：

- UI 字体整体稳定，但字号层级细碎。
- 小字太多，且在复杂背景上显浅。
- 版本标题、事件标题、候选标题常被截断。

组件一致性：

- 按钮有圆形、矩形、浅色、橙色、文字、图标多套风格。
- 弹窗和抽屉风格不完全一致。
- details/summary 用得多，容易形成默认网页控件感。

AI 味来源：

- 过多“AI 推荐 / 智能 / 生成 / 计划 / 检索诊断”等标签堆叠。
- 大量卡片、badge、渐变/光效/进度条同时出现。
- 文案解释过多，像在证明 AI 正在工作，而不是让用户直接剪辑。

## 32. 给重设计 AI 的输入约束

重设计目标：

- 保留专业剪辑工作台定位。
- 让视频预览和时间线成为视觉中心。
- 左侧对话区应该辅助任务，不应抢主舞台。
- 降低线条密度，减少卡片套卡片。
- 统一深色表面，清除白色/浅色残留。
- 降低橙色使用频率，让橙色只用于最高优先级动作或播放头。
- 让时间线、候选、成片版本更易读。
- 让“直接输入要求”和“选择快速模式”并列清楚。

必须保留的交互入口：

- 新建任务 / 上传视频。
- 当前任务 / 任务列表 / 成片库 / 设置。
- 对话输入。
- Agent Skill 菜单。
- 4 个快速模式。
- Agent 计划查看与确认。
- 源视频和成片版本切换。
- 播放器控制。
- 主时间线。
- 候选镜头抽屉。
- 人物和说话人面板。
- 封面时间线。
- 二次精剪入口。
- 字幕校对入口。
- 下载/导出入口。

建议重设计时重点处理：

- 用更少、更明确的区域承载状态，不要把每个状态都做成卡片。
- 用层级、空间、颜色权重替代大量边框。
- 时间线轨道要优先保证文字、缩略图、播放头、选区可读。
- 成片版本区应像“版本比较器”，不要像三张广告卡。
- Agent 计划应是可展开辅助信息，不能遮挡视频区域。
- 技术诊断默认折叠，只在用户需要时展开。
