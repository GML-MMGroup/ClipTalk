# 界面字体与字号优化

## 范围与选择

只调整网页操作界面，不修改视频字幕、封面成图、文本图层的字体，也不改业务逻辑。

已盘点 `fonts/` 的 17 个字体文件。采用本地 `SourceHanSansSC-Bold.otf`
作为标题字，生成独立的 `VP Interface Heading` 网页子集。正文继续使用已本地化的
Noto Sans SC，英文和时间数字使用 Inter。保留真实的常规、中等、半粗与粗体字重，
不用浏览器合成粗体。思源黑体与正文黑体结构接近，适合长时间操作。

霞鹜文楷、行书、手写、像素和装饰字体不用于密集的按钮、表单、时间轴。
不因为文件可用就混用所有字体；原始字体文件均保留。

## 字号层级

| 用途 | 字号 | 处理 |
| --- | --- | --- |
| 助手主标题 | 20px，小屏 18px | 本地思源黑体 Bold |
| 视频标题、精剪标题、设置弹层标题 | 16px | 明确层级，不加装饰字距 |
| 对话正文、需求输入 | 15px | 正常字重，正文 1.75 倍行高 |
| 表单字段 | 14px | 清晰黑体，小屏输入区 16px |
| 按钮、标签、说明 | 13px | 不再为塞进工具栏缩小到 9–10px |
| 状态、时间数字 | 12px | 时间采用等宽数字特性、直立字体 |
| 时间轴密集刻度和片段标记 | 11px | 保留紧凑轨道，不影响缩略图与波形 |

## 实现与适配

- `typography.css` 管理字体资源与公共字号变量；`theme.css` 引用同一字体变量。
- `interface-type.css` 用独立 cascade layer 管理界面文字角色，覆盖旧的高优先级
  小字号，避免继续堆叠重复 ID。只对列出的 UI 元素生效，不泛化到所有按钮或画面文字。
- 工具栏和时间轴标题允许换行；窄桌面限制侧栏宽度，防止旧保存尺寸把右栏挤出屏幕。
- 三栏同时展开的窄桌面中，播放进度条单独占一行，避免前后片段按钮覆盖时间数字；
  音量、倍速与全屏入口保留。侧栏收起后维持原有宽屏播放控件布局。
- 使用 `font-display: swap`；缺字或字体加载失败时回退到 Noto 与系统黑体。
- 只按需加载一个新增标题字文件，不把整个 `fonts/` 下载到浏览器。
- `python3 tools/build_webfonts.py --ui-only` 可重复构建；不重写原字体与其他网页字体。

## 验证要求

- 检查真实计算字体，而非仅检查 CSS 文件；确认新增字体已加载。
- 浅色/深色、1920/1366/390 等宽度下验证正文、控件、设置弹层与精剪布局。
- 验证弹层没有越界、发送按钮仍同排、精剪导出操作可见、片段媒体轨道不重叠。
- 使用浏览器只读访问现有任务，禁止为了截图写入任务或触发生成。

- 5 个前端测试文件共 146 项通过；播放器最后一轮适配后的 5 项相关复测通过。
- 前端 lint、差异空白检查、字体构建脚本语法检查通过。

  新增回归用例覆盖深浅色正文、弹层、侧栏边界以及画面字幕字号不被覆盖。

  覆盖的旧声明；保留最终生效值，删除因此变空的规则。`npm run audit:css`
  现为 0 告警，没有修改审计规则或增加忽略项。
- 清理前后，真实精剪页面在深浅色 × 1920/1366/390 三档宽度下，9 类相关控件的
  计算样式完全一致。补充生产样式零重复回归检查，防止失效声明再次累积。
