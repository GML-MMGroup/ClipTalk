# 界面一致性修复（2026-09-10）

## 已实现

- 素材与结果中的“版本”打开实际版本列表，复用原有卡片和操作绑定，支持返回概览。
- 统一所选输出；没有选择时优先最新正式视频，其次最新审核样片。查看源素材不重置交付卡片的版本。
- Agent 审核样片通过真实精剪会话编辑、生成，不再把虚拟版本标识传入普通版本接口。
- 生成确认绑定任务、版本或会话修订；任务、时间线或字幕变化时明确取消并提示。过期预览禁用正式生成，保留单一更新样片入口。
- 正式生成、下载 MP4、存入成片库分别命名。移除永久重复的“导出完成”按钮；新增文件使用一次性反馈，并绑定对应文件。
- 旧输出缺少尺寸时按实际文件缓存探测，不用源视频尺寸推断；未知画幅显示待检测，缺少质量报告不视为通过。
- 流程统一为准备素材、确认方案、筛选与编排、审核样片、生成与交付。计划执行详情保留一个入口。
- 精剪排期、变速和转场共用时间线计算；导出检查与未保存修改分开显示，声音等警告不再标成无条件检查通过。
- 项目新增 `outputFit`（blur/crop），PATCH 保留未提交的字段。新建时间线采用项目默认值，已有输出和精剪会话保留自身画幅。
- 本机任务名称用于工作区标题、任务卡片和本地目录搜索。Agent 设置增加脏状态、放弃修改与验证后保存，并防止异步加载覆盖输入。
- 浅深主题使用现有语义色；媒体遮罩文字独立保持高对比。修复旧结果卡、时间轴标题、播放时钟、倍速和适配下拉框。
- 素材预览默认紧凑、可展开；首页移除上移变换并允许滚动；窄屏主导航收进菜单，避免覆盖工作区。
- 成片库空状态可打开任务列表，失败可重试；播放失败、暂停和结束同步按钮状态。

- ESLint、Python 静态检查、前端所有权与 CSS 层叠审计。

## 生效说明

静态资源缓存标识已更新为 `20260910-ui-consistency-3`。部署时需要同步更新前后端并重启后端，然后刷新浏览器。

本轮没有直接重启监听 5191 的既有后端进程：该进程仍加载旧版本，目录中同时存在 Agent 规划/运行状态。任务、视频和精剪草稿均保留。应在确认没有正在执行的计划或渲染后安排服务重启；旧预览若不符合当前渲染契约，会提示重新生成，而不会冒充最新预览。
