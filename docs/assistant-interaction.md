# AI 剪辑助手交互与引用

## 消息与执行分离

新版输入框经 Agent 消息接口提交 `clientMessageId`、`uiContext` 和 `replyToActionId`。同一消息重试返回原处理结果，不重复创建计划；原有不带这些字段的规划调用仍兼容。工作区 `messages` 保存消息 ID、状态、方案关联和处理结果，刷新时与旧任务消息合并。旧方案中可确认的原始要求可补齐展示，不编造缺失对话。

输入先做保守意图分流：询问只读取已有证据回答；反馈和不明确的要求先澄清；明确剪辑要求才进入规划。回答模型不可用时返回已保存事实，不降级为编辑。自然语言确认绑定用户实际看到的方案 ID 和哈希；片段审核同时携带已保存的结构化选择，复用原审核校验。正式导出仍必须使用独立确认入口。

## 引用与生命周期

- 输入框显示当前检索选择、播放对象和时间选区；发送前冻结引用，不因清空输入丢失播放位置。
- 服务端验证任务归属、检索 ID、片段 ID、候选证据指纹、输出文件引用和时间域。方案批准时再次校验，内容合成使用已绑定的顺序，不悄悄改用保存后的其他选区。
- 修改已有输出时绑定其关联时间线及修订号，创建独立编辑草稿，保留引用输出的画幅。找不到指定输出时不回退其他视频；同一计划先修改时间线再改画幅时使用新样片，不重新使用旧文件。
- 通用任务 revision 包括进度变化和工作区创建，不作为前端引用的唯一指纹；可选旧客户端 revision 校验仍保留。候选和版本使用专门引用校验。
- 新检索不会把旧候选绑定为新检索结果。同源派生任务仅在没有固定片段或输出版本引用时允许继承来源上下文。
- 待确认方案先生成替代方案，成功后在执行锁内切换；生成失败保留旧方案。确认按钮与替代生成互斥。
- 执行中修改持久化暂存。用户决定停止后规划、完成后整理、撤回。暂存冲突或不同范围要求澄清；后台 Future 未实际结束，不重复启动。完成后整理的方案仍需批准。
- 人工证据审核通过结构化确认重新绑定范围并保存前后引用记录，不能跳过时间线提案步骤。

## 展示

当前方案默认折叠为紧凑状态摘要，生成前显示本次参数与来源。步骤、日志和检查详情在抽屉中。预览按计划产物或明确 planId 归属筛选；历史预览不会冒充当前结果。对话恢复包含方案要求与终态消息。引用标签换行，使用浅深主题语义色。

## 保守处理边界

- 目前意图入口使用可测试的规则分流，不确定表达会澄清，不自动猜测执行。
- 多时间选区及事件组合继续使用现有专用合成按钮；助手提示对应入口。样片播放位置不能直接当作源视频剪辑坐标，修改需在精剪时间线明确范围；询问可保留样片坐标。
- 中断规划、断线及重启后，暂存要求可恢复；若无法证明后台操作停止，保留修改并要求核实。完成后整理若未恢复，可点击“检查并整理修改”。
- 没有核验记录不展示为核验通过；技术质检不能证明内容匹配。旧版本中的历史文案保留作为历史记录。

## 验证与部署

隔离测试覆盖只读询问、流式回答、幂等、替换失败保留旧方案、暂存冲突、实际停止等待、引用失效、人工重绑定、同源派生，以及浏览器输入清空、重试 ID 与中文输入法。

实现不自动重启服务，不重生成或删除历史任务。后端重启与前端刷新需配套；不要在后台渲染尚未结束时重启。浏览器恢复核验使用只读请求，在线模型与真实媒体渲染不作为单元测试依赖。
