# 自动交付改造与验收记录

目标：首次配置后，添加视频、提交要求、下载结果。旧任务不自动启动，旧审核模式保持兼容。

## 已实现

- [x] 新增 `automatic_delivery`，前端默认“自动完成”，保留“自动到预览”和逐步确认；旧任务不切换模式。
- [x] 核心托管剪辑计划可在提交要求后自动批准；正式导出授权只覆盖本次计划的核心交付工具，不扩大到插件、删除或外部发布。
- [x] 从冻结的源视频时间线、字幕和画幅规格重新生成正式文件，不复制带水印的审核代理文件充当成片。
- [x] 只有明确要求时才合成封面片头；保存封面与合成片头保持独立，默认片头为 1 秒。
- [x] 交付绑定计划、时间线版本、字幕指纹和封面版本；重复执行复用完整文件，取消或版本变化时不提交旧结果。
- [x] 明确质量错误阻断；可定位的时长、画幅或内容错误最多自动重跑一次相关步骤，一般提醒不要求逐项点击确认。
- [x] 自动校对只应用低风险字幕建议；对白字幕重叠风险采用保守源帧抽查，不确定时暂停询问，不伪造用户确认。
- [x] 修复“不剪辑、不生成视频”被误解析为剪辑要求；只检索的请求不追加正式交付。
- [x] 新建任务默认一个版本，能力选择折叠；首次配置先显示下一项必需设置，已配置项目与可选能力折叠。
- [x] 对话区默认 360px，可拖至 320px，保留个人已保存宽度；微小辅助文字基准提高到 12px。
- [x] 首页区分需要回答、处理中、未完成、结果与最近任务；任务名称与说明分行，避免多个字段挤在同一行。
- [x] 自动交付完成后提供当前正式文件下载；不再提示重新确认导出，不把本次已完成方案误折叠为历史。
- [x] 执行状态区分生成正式视频与生成预览；正式视频已存在但最后检查未结束时，不抢先宣告整个任务完成。
- [x] 音频优化、独立动态图文、动态图文片头接入同一个正式交付工具；音频优化复制原视频流，不重编码画面。
- [x] 连续音频/动态图文修改使用本次选定的正式文件，保留上次效果；文件名不再逐轮增长；独立动态图文不绑定旧任务封面，不默认添加产品标记。
- [x] 修复“不加字幕/不做封面”“添加对白字幕”“标题写：…”与“把封面放在视频开头”的常用表达；区分片头长度、正文长度、封面文字和视频叠字。
- [x] 封面放在开头 1 秒不再误限素材为源片前 1 秒；“剪成指定时长并添加封面”仍会剪辑正文。自动模式只在正式合成后做一次最终质检，不重复合成审核片头。
- [x] 自动时长收敛使用方案里公布的容差，不再另用更窄的限制误报无结果；明确零容差仍严格检查。
- [x] 不同画幅封面合入成片时完整保留标题和边缘；源片字幕检测改用清晰单帧，并检查内嵌画面中的字幕，发现已有字幕或不确定即暂停询问。
- [x] 兼容模型返回的两种白名单编辑操作结构，仍校验真实片段编号和范围；无效结构最多要求模型修正一次，不伪造成功的剪辑操作。
- [x] 跨子任务执行仍从当前计划读取要求，字幕、封面与文字质检不再依赖可能缺失的子任务 brief。
- [x] “保留指定说话人的全部发言”不再拿内部流程说明做关键词搜索；已核验且不超过 0.5 秒的边界收紧，在自动模式下直接继续，其他变更仍需确认。
- [x] 人物歧义时直接打开选择面板，真实选择保存后才显示继续；不默认冒认目标人物。
- [x] 可选 SigLIP 去重只读取本地模型，未安装时使用既有图像哈希降级，不在基础剪辑过程中隐式下载并卡住。
- [x] 保留现有视觉体系，修正浅色时间轴辅助文字、AI 头像与深色首页说明/链接的对比度；测量工具支持渲染背景采样及深色模式。
