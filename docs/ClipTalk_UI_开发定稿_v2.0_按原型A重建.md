# ClipTalk UI 开发定稿 v2.0
## 按原型 A 重建工作台，不在旧界面上换肤

版本：2.0 · A 版构图锁定版  
日期：2026-09-06  
适用：前端开发、编码助手、设计验收与测试  
交付状态：开发规格已修订；未接入用户项目，未验收当前实现

> **本次交付的是新的工作台界面层，不是旧页面的主题补丁。原型 A 决定构图、区域比例、组件形态和视觉重点；现有能力盘点决定必须保留的功能与业务边界。保留业务不等于保留旧 DOM、旧卡片、旧布局或旧 CSS。**

## 00. 执行依据、优先级与作废范围

### 0.1 三份依据各自负责什么

| 依据 | 文件 | 决定什么 | 不决定什么 |
|---|---|---|---|
| A 版视觉基准 | `reference/原型A_验收基准.png` | 主构图、深浅关系、左栏品牌与聊天、中央预览、右侧独立托盘、胶片式内容 | 不能凭示意图新增账号、音乐生成、真实人物身份识别等后端能力 |
| 本开发定稿 | 本文件 | 将 A 版转成实际网页的尺寸、结构、组件、状态、功能位置和验收要求 | 不假称已核对真实仓库代码 |
| 现有能力盘点 S1 | `source/现有界面盘点.md` | 必须保留的上传、四模式、计划、审核、编辑、版本、字幕、封面、设置等业务 | 旧布局、DOM 层级、样式和技术信息展示方式不具有保留优先权 |

源图片为 1536×1024 像素。本文所有 CSS 尺寸是为真实工作台制定的规格，不是声称从图片逐像素提取的值。没有当前改版截图和仓库源码，本文不对实际代码改动、接口路径或当前视觉偏差作未经核实的断言。

**不再把“功能覆盖 > 原型视觉”写成一条允许随意改布局的总排序。** 改为两个并行的硬门槛：视觉必须符合 A 版，业务必须完整、安全。出现冲突时调整组件内部、展开方式或页面路由；不得静默牺牲其中一项。需要改变本文件锁定的构图时，提交具体偏差及原因，得到确认后再改。

### 0.2 v1.0 哪些内容失效

v1.0 主文档及 `tokens.css` 不再作为新界面的布局、视觉、组件结构或迁移依据。以下要求明确作废，不得同时执行：

| v1.0 的处理 | v2.0 的替代 |
|---|---|
| “视觉参考第一版”，但把具体交互规则与功能覆盖整体排在视觉之前 | A 版为视觉验收基准；业务与视觉分别验收，不能以功能借口回到旧外观 |
| 大品牌字标缩小，品牌导航压成密集工具行 | 恢复独立品牌区、大字标、宽的新建任务按钮 |
| 右侧错层托盘改为规整停靠栏 | 恢复独立、下沉的右托盘；用布局行偏移实现，不遮挡中央内容 |
| 浅色卡只保留分类头或小面积色块，主要用紧凑深色列表 | 概览使用有实际内容的大面积柔和彩色卡；深入结果后再切密集列表 |
| 底部素材胶片带不默认常驻 | 恢复中央底部的紧凑胶片带，用真实已有素材或候选投影，不新增媒体库业务 |
| 1280—1439 宽度默认收起右栏 | 1280 CSS px 及以上默认完整显示三列；1366 不得直接退化为旧双栏 |
| 保留现有 ID、先加样式根节点、移动原节点 | 新建界面结构与渲染层；旧行为经纯数据/命令适配器接入，不搬旧面板 |
| 先做外壳主题，最后统一视觉验收 | 独立渲染的新工作台先过视觉关，再接业务，再逐阶段回归 |

v1.0 中有效的确认、隐私、版本保护与数据一致性要求，已在本文件重新列出；不得因为作废其视觉方案而取消这些业务保护。

### 0.3 交付边界

不要求迁移现有前端框架，不重写 Agent、分析模型、视频编解码或渲染服务。要求重建的是：页面壳、区域布局、消息与结果的展示组件、工具栏、面板、控制条、轨道外观以及动态渲染入口。

也不要求“所有旧代码清零”。允许保留与新视觉无关的纯算法、API 客户端、状态数据、媒体控制器和经审查的基础组件；禁止旧视觉结构决定新工作台形状。

## 01. 原型 A 必须保留的八个特征

### 1.1 构图签名

1. **暖米色画布托住深色工作台。** 它是清楚可见的外部环境，不是边缘一条几乎看不到的色线；内部保持墨绿炭色，不变成蓝黑霓虹风。
2. **左栏有独立而清晰的品牌头部。** 现有 Logo、大字标、“新建任务”宽按钮与少量导航，下面才是助理内容。
3. **中央是有边界的视频工作台。** 项目工具栏、视频与播放控制、时间线、底部胶片带上下连续，而不是在旧页面空白里放一个播放器。
4. **右侧是独立且下沉的工具/结果托盘。** 与主板通过间距、顶部错层和圆角区分，不与中央共用一根贯穿的顶部工具条。
5. **右侧概览有真实承载内容的柔和彩色卡。** 卡片里有缩略图、片段关系或实际状态，不能只剩彩色小图标与一排深色表单。
6. **浅绿色承担品牌操作与剪辑反馈。** 新建、发送、播放、关键确认以及选区形成统一语言；不沿用旧橙色按钮与播放头。
7. **媒体内容是主要视觉材料。** 视频、缩略图、胶片与波形是内容，不用文字说明、日志和状态徽章替代。
8. **输入框始终稳固地位于左栏下方。** 消息和计划在中部滚动，不能向下挤走输入框。

以上是本次设计的硬性特征，不是可供开发自由“简化”的装饰清单。

### 1.2 明确允许的产品化调整

只允许以下已经定义的转换，不需要重新解释风格：

- 全部操作文案中文化，保留产品名 ClipTalk。
- 使用现有真实 Logo 与助理图标；不能从生成图描摹出另一套品牌。
- 不实现浏览器里没有意义的三色窗口按钮、BETA 标签、账号头像与会员入口。
- 不把视频中的手写标语叠加到真实用户媒体上；也不让大机器人占用播放器或右托盘点击区域。
- 四个快速模式以 S1 为准，不保留图中第五个无业务支持的“音乐”入口。
- 没有真实音乐能力不画可交互的 Music 轨；用现有视频、音频、字幕/事件轨保持胶片式层次。
- 右侧四种模式卡不必在每个业务阶段同时出现。草稿态展示四种入口；审核态展示真实当前结果；结果概览仍保持图像优先、柔和卡片的形态。

不能把这份允许清单扩展为“所有与旧页面不一样的地方都可删除”。

## 02. 新界面结构：先建新树，再接旧业务

### 2.1 工作台结构

以下名称是新结构的职责命名，不要求引入特定框架。原生模块、现有模板体系或已有组件框架均可实现相同结构。

```text
StudioPageV2                         暖米色画布，唯一工作台根
├─ MainBoardSurface                  左栏＋中央背后的深色主板背景
├─ AssistantPane                     左列，独立滚动区
│  ├─ BrandHeader                    现有 Logo＋大字标
│  ├─ TaskNavigation                 新建任务／任务／成片等
│  ├─ AssistantContext               素材摘要、助理身份
│  ├─ ConversationViewport           消息、轻量计划、阶段消息
│  ├─ Composer                       固定输入框及工具菜单
│  └─ UtilityFooter                  服务、设置、返回工作区
├─ EditingStage                      中列，纵向网格
│  ├─ ProjectToolbar                 任务名、媒体选择、精剪/导出入口
│  ├─ ViewerCard                     视频舞台＋一个播放控制条
│  ├─ TimelinePanel                  工具栏、标尺、真实轨道
│  └─ ContextFilmstrip               紧凑横向素材/候选带
├─ ContextTray                       右列，下沉的独立托盘
│  ├─ TrayTabs                       剪辑／素材／版本
│  ├─ TrayRoute                      概览、结果、对象详情、校正、设置
│  └─ ContextAction                  当前上下文摘要与一个主要动作
└─ OverlayHost                       菜单、必要确认、全量校对等
```

**外观上为三列、两个大体块：左＋中央组成主板，右侧是独立托盘。** 不能将其实现为旧的 72px 导航轨＋对话＋审核的四列结构，也不能把右托盘插到时间线下方。

### 2.2 导航与功能入口归属

| 入口 | 新位置 | 说明 |
|---|---|---|
| 首页 | 左上 Logo | 品牌按钮可访问，离开时处理未保存编辑 |
| 新建任务 | 左栏品牌下方的宽浅绿按钮 | 不是新建聊天；沿用现有任务建立规则 |
| 任务列表 | 新建按钮旁的历史图标 | 文字提示“任务列表”，打开左侧任务面板 |
| 当前任务 | 左栏低权重导航或面包屑恢复入口 | 无任务时明确禁用，不伪造任务 |
| 成片库 | 左栏导航文字入口 | 独立管理页，同一视觉语言 |
| 服务、设置 | 左栏底部工具行 | 不占中央顶部工具栏 |
| Skill、执行方式、快速模式 | 左栏输入工具菜单 | 草稿态同时有右侧四模式入口，两处共享状态 |
| 候选镜头、内容结果 | 右托盘“素材”及“剪辑”结果页 | 不再在聊天底部重画全份列表 |
| 人物、说话人 | 右托盘当前剪辑流程的对象页 | 保留全部校正能力 |
| 封面、字幕、精剪 | 版本/项目上下文动作 | 专门编辑模式，不混进默认首屏 |

### 2.3 禁止复用的视觉结构

不挂载旧 `appSidebar` 作为常驻窄轨；不将整个旧 `reviewView`、`chatStageHost`、`candidateDrawer`、`secondaryEditor` 容器直接塞进新卡片；不让旧计划卡、旧版本卡或旧表单组继续负责新页面渲染。

允许抽取上述模块中的业务数据与操作函数。允许媒体控制器把视频元素引用作为参数接入。允许在独立回退页面暂时保留旧版，但**同一个活动页面不能同时运行新旧两个工作台**。

## 03. 桌面几何定稿

### 3.1 基准、列宽与响应式

以 **1536×1024 CSS px** 检查 A 版构图；同时以 **1440×900、1366×768、1280×800、1920×1080** 检查真实桌面使用。截图尺寸、浏览器缩放和设备像素比必须记录。

三列净宽的定义：视口宽度减去两侧外边距、两处列间距后，依次分给左栏、中央、右托盘。中央内部的右内边距计入中央列宽，不再从全局重复扣除。

| 视口宽度区间 | 两侧外边距（每侧） | 左栏 | 右托盘 | 列间距（每处） | 代表视口的中央列宽 |
|---|---:|---:|---:|---:|---:|
| ≥1800 | 32 | 336 | 392 | 12 | 1920 时 1104 |
| 1536—1799 | 24 | 312 | 368 | 12 | 1536 时 784 |
| 1440—1535 | 24 | 296 | 340 | 12 | 1440 时 732 |
| 1360—1439 | 16 | 280 | 316 | 12 | 1366 时 714 |
| 1280—1359 | 16 | 264 | 300 | 12 | 1280 时 660 |

高度方向：工作台可用高 `H = 视口高 − 2 × 外边距`。外边距默认与上表一致；视口高小于 800 时上下外边距统一 16px。工作台根使用视口高度，内部独立滚动。

**在 1280 CSS px 及以上，默认三列完整展开。** 不得以旧布局的中央最小宽度常量为由自动收掉右托盘。用户主动收起可保留；视觉验收时须重置布局到本版本默认值，不能继承 v1 保存的折叠状态。

### 3.2 两个大体块的形态

主板背景：覆盖左栏与中央列及其中间距；圆角 24px；底色 `#1D2525`；外阴影为低对比暖暗影。它不覆盖到右托盘列。

右托盘：完整宽度按上表；默认顶部比主板低 80px；底部与主板对齐；圆角 20px；底色 `#25302F`。高小于 900 时顶部偏移减到 64px，高小于 800 时减到 48px。不得借用负 margin、绝对定位叠住视频或让实际可点击卡片漂出托盘。

顶部偏移是一段真实的布局留白，最多放一条小字帮助提示，默认可为空。不得自动塞入机器人、宣传标语或多余账户区域。

左栏与中央之间仅用表面层次和间距区分；右托盘的独立轮廓必须可见。不要给每个嵌套容器都加同样的全边框与投影。

### 3.3 中央纵向布局

中央列内部：左内边距 0，右内边距 12，上下各 12；有效内容高 `Hc = H − 24`。内部按“项目工具栏 / 播放器 / 时间线 / 胶片带”排列。

| 高度条件 | 工具栏 | 三处纵向间距 | 时间线 | 胶片带 | 播放器 |
|---|---:|---:|---:|---:|---|
| 视口高 ≥1000 | 56 | 每处12 | 244 | 76 | 占剩余 |
| 800—999 | 52 | 每处12 | 212 | 68 | 占剩余 |
| <800 | 48 | 每处8 | 172 | 56 | 占剩余 |

例：1536×1024，H=976，Hc=952，播放器高为 `952−56−36−244−76=540`。1440×900，H=852，Hc=828，播放器高为 `828−52−36−212−68=460`。1366×768，H=736，Hc=712，播放器高为 `712−48−24−172−56=412`。

上述是首次进入的默认值。拖动时间线高度时，播放器至少保留 280px（含控制条）；达不到时改为轨道内部滚动。不得把播放器压缩为顶部一小条，或为了画出很多轨道让中央出现页面级纵向滚动。

### 3.4 左栏纵向结构

品牌区 80px（含内边距），Logo 40px，字标约 32px/40px，字号可依据现有字标资源外框微调，但不可降到普通 15px 面板标题的量级。现有字标若为图片，保持原宽高比。

新建操作行 44px，左右内边距 20px；主按钮占可用宽度，旁边任务历史按钮 40px；下方导航采用一行轻量文字，不加第二层 72px 窄轨。

素材与助理摘要不超过两块短行；对话区用剩余高度。输入框默认 116—136px，自动增长到 196px 后内部滚动。底部工具行 32px。高度小于 800 时压缩品牌区到 68px、输入框最低 100px，不缩小正文到难以阅读。

### 3.5 小屏与布局记忆

1024—1279：允许保持左＋中央，右托盘通过明确入口覆盖右侧局部；此模式仅为窄屏适配，不能作为桌面验收截图。打开右托盘时中央保留可见预览；复杂详情改为单一工作区视图，不强塞三列。

小于 1024：显示“对话 / 预览 / 剪辑”视图切换，共享同一任务状态。保留上传、输入、计划确认、预览、结果选择与下载。复杂多轨精剪可提示需要更宽窗口，字幕文本校对仍可进入。

布局记忆使用新的版本键，例如 `studio-layout-v2`，仅存尺寸与展开状态。读取旧版布局值必须迁移并校验，不能把旧右栏的 48px 折叠宽度带进默认 A 版。

左右宽度拖拽仅在当前视口满足中央有效宽度至少 620px 时允许；默认列宽不需调整。12px 列间距内设置拖拽命中区，分隔线仅悬停/聚焦时出现。双击恢复当前断点默认值；键盘以 8px 调整；释放、失焦和取消拖拽都正常结束。

## 04. 视觉系统与真实组件形态

### 4.1 颜色

| 用途 | 定稿值 | 约束 |
|---|---|---|
| 外部暖米背景 | `#F2ECE3` | 禁止改为深色全屏底；窄屏单视图可去外边距 |
| 主板 | `#1D2525` | 偏墨绿炭色，不偏蓝紫 |
| 左栏 | `#202929` | 与主板形成很轻的表面差 |
| 右托盘 | `#25302F` | 独立体块，不画亮描边 |
| 播放器舞台 | `#111918` | 容纳横竖媒体的真实留白 |
| 控件/消息浅层 | `#2B3634` | 不为每行创建不同底色 |
| 结构线 | `#3D4B45` | 单线，不能叠两层 |
| 输入可辨边界 | `#718376` | 只用于必要交互边界 |
| 主文字 | `#F1F3EC` | 用于深底 |
| 次级文字 | `#C4CDC5` | 正文辅助 |
| 元信息 | `#A9B7AD` | 不再乘低透明度 |
| 主浅绿 | `#C8DDA9` | 新建、发送、播放、关键操作 |
| 主操作文字 | `#203022` | 浅绿上深字 |
| 悬停浅绿 | `#D7E6BF` | 无发光 |
| 选区底 | `#364735` | 边缘用主浅绿，保持缩略图可见 |
| 播放头 | `#C8DDA9` | 与原型 A 一致；不延续 v1 橙粉色播放头 |
| 成功 | `#9BC9A1` | 必须配状态含义，不与已选混用 |
| 警告 | `#E6C486` | 有真实待复核/阻塞才显示 |
| 危险 | `#DCA49A` | 删除与失败，不充当装饰强调 |

四种柔和彩色：说话人 `#F6E6C1`、人物 `#DCE8DA`、内容 `#D5E2F2`、高光 `#F2D4CD`。浅卡标题 `#203026`，正文 `#405447`，按钮/焦点边 `#386247`。

**彩色的使用单位是“概览卡片”，不是只给一条细线着色。** 单张概览卡应大面积使用对应浅底；其文字必须转为深色。深层列表可以使用深色底以支持高密度，但不能把默认概览直接做成后台数据列表。

不再设置“全站浅色占比不得超过 12%”一类会迫使开发删掉 A 版特点的总量限制。直接检查颜色的位置、组件层级及与视频的平衡。

### 4.2 字体、间距、圆角

UI：优先使用项目已有的可用中文无衬线字体；可用栈 `Inter, Noto Sans SC, PingFang SC, Microsoft YaHei, sans-serif`。不得为交付复制字体文件。

| 层级 | 字号/行高 | 字重 |
|---|---|---|
| 品牌字标（文字实现时） | 32/40 | 600，保留品牌资源特征 |
| 独立管理页标题 | 24/32 | 600 |
| 助理/托盘标题 | 16/24 | 600 |
| 概览卡片标题 | 15/22 | 600 |
| 正文、主要按钮 | 14/22 | 400/500 |
| 时间、次级说明 | 12/18 | 400/500 |
| 时间线刻度 | 11/16 | 500，仅用于标尺 |

基础间距采用 4、8、12、16、20、24、32。外壳圆角 24，托盘 20，播放器与主内容块 16，结果概览卡 14，输入框 12，按钮 10，片段 5。

阴影只给主板、托盘和真正浮层；嵌套卡片不叠厚阴影。禁止紫色发光、荧光渐变、所有边缘统一描亮、所有消息套粗边框。允许极轻表面明度变化，但不用纹理噪点遮盖低质量排版。

### 4.3 按钮、图标与消息

主按钮默认 40px，高度紧凑时 36px；新建行 44px；播放圆按钮 40px；图标按钮 32px，触摸模式扩大命中。图标使用同一现有 SVG 家族，16/20px，线宽统一。不用 emoji 代替真实控件。

工作台上只在当前有意义的区域使用主按钮。发送可常驻；草稿态右卡是模式选择，不同时摆四颗“开始”绿色大按钮。顶部“导出”可见但无成片时禁用并提供原因；计划确认发生在左栏，当前生成动作发生在右栏。

助理正文开放排布，不每条都包厚卡；用户消息可用抬高一层的深色气泡。计划摘要是消息流中的一个轻量单元，内容最多一段摘要、一个状态、一个主要动作，技术明细进入详情。

所有按钮有默认、悬停、按下、键盘焦点、禁用、执行中与失败恢复状态。输入法组词时 Enter 不发送；禁用不是简单去掉点击事件而无说明。

## 05. 三种必须先完成的首屏

### 5.1 S0：素材就绪，尚未输入要求

**目的：** 验收 A 版构图，同时确保第一次使用者知道如何开始。

左侧：品牌、新建、素材摘要、一段助理引导、输入框；保留四种快速模式的紧凑入口，可通过输入附近的“剪辑方式”展开。右侧默认“剪辑”标签，四张柔和彩色模式卡完整可达。中央显示真实本地预览；时间线没有分析结果时只显示合法源片范围或单条素材带，不伪造镜头、波形或字幕。

右侧四卡推荐顺序与原图色彩关系一致：按说话人剪辑、按人物剪辑、内容探索、高光剪辑。它们是并列模式，**不标为 1→2→3→4 的执行步骤**。

### 5.2 S1：计划已确认，分析运行中

左侧保留真实用户要求与单个阶段摘要，例如“正在查找相关片段”；提供停止与活动详情，不显示伪百分比。中央依然可看原视频；没有结果的时间线不被 loading orb 遮住。

右侧保持当前模式的柔色头卡，卡内显示目标、实际处理状态；下方为真实已产生的结果或短骨架。其余模式入口折入“切换剪辑方式”，不得把四种模式同时画成全部正在运行。

### 5.3 S2：审核结果就绪或已有成片版本

左侧只有简短结果总结，不在消息底部重画所有片段。中央播放器、时间线、胶片带均显示同一上下文。右侧剪辑页默认显示图像优先的结果概览卡；可切“列表”深入选择，选中对象进同托盘详情页。

已有版本时“版本”标签显示大缩略图与版本元信息，顶部媒体选择显示明确源片或 Vxxx。版本不必固定三份。右栏生成当前结果、顶部导出当前版本两种动作按上下文区分，不把两者都写成“应用”。

**三种首屏必须分别通过验收。只做好空态或填充漂亮演示文字，不算工作台完成。**

## 06. 右侧托盘：不要再退回深色表单栏

### 6.1 托盘导航

一级标签固定“剪辑 / 素材 / 版本”，高 44px，左右内边距 16。选中态为深色抬高面＋浅绿下边或清楚的底色差；不能只改变难以分辨的文字灰度。

剪辑页内部路由：`模式概览 → 当前流程 → 结果概览 → 对象详情/分组校正/生成设置`。同一托盘只展示一个主层级。进入详情有返回标题与上一级选择摘要；Esc 返回一层，不清空选择。

### 6.2 四种模式概览卡

常规托盘宽 368，内边距 16，卡宽 336。卡高默认 132—148，间距 12。1440 下可用卡宽 308；1366 下可用 284；最小桌面下为 268。短高窗口容许内部滚动，不通过缩小文字和缩略图硬塞四张。

每卡结构：上部图标＋标题，最多一行简短说明，下部 60—72px 的可视内容。不得用一大段说明文案填满下半卡。

| 模式 | 可视内容 | 点击行为 |
|---|---|---|
| 按说话人剪辑 | 有结果时显示真实发言样本/波形片段；未分析时用清晰的功能示意与“示意”标记 | 选择模式并打开必要设置，不立即分析 |
| 按人物剪辑 | 已识别人脸代表画面；未识别时使用中性轮廓示意，不编造人物身份 | 进入识别/目标确认流程 |
| 内容探索 | 当前素材真实缩略图＋描述入口；无缩略图时用简单结构示意 | 焦点进入描述输入，保留当前文字 |
| 高光剪辑 | 当前素材预览＋可选时长/版本数摘要；不默认写死 60 秒 | 展开高光设置，不立即生成 |

四卡均用大面积对应浅底，不使用“深底＋左侧 3px 彩线”代替。示意图只能表现能力，不标记“已识别三人”“生成成功”等未发生的事实。

### 6.3 结果概览与密集列表是两种视图

**概览是默认的视觉页面，列表是深入审核工具。**

结果概览卡：标题行、144—180px 横向主图或 2—3 张镜头拼接、时间与片段数、一个状态、预览/选择。用当前模式的柔色表面；同一结果集不用随机轮换四种颜色。长理由、全部转写、分数解释、模型调用不展开。

“查看全部 N 段”进入列表。列表可用深底、88—100px 行高、约 96×54 缩略图，保证复选框与标题清楚。列表头部保留当前模式柔色摘要，避免深入后完全丢掉 A 版语言。

只有一条结果就显示一条，不复制成四卡。没有缩略图可显示“缩略图生成中”占位，不能用同一演示人像假装不同视频片段。

### 6.4 选择、详情与底部动作

卡片/缩略图点击预览；复选框改变选择，两者分开。聚焦/播放与勾选分别编码，不能只有一个浅绿状态。筛选隐藏已选项时说明“另有 N 个已选项不在当前筛选中”。

底部动作区固定，正常 64—88px；展示已选数量、源片时长或真实预估值、一个主要动作。生成设置收在这里的二级页，不在每张卡重复一组下拉框。

详情顺序：标题与范围 → 真实理由 → 转写/画面/声音证据 → 边界编辑 → 技术详情。精细边界输入、删除、加入当前选择、下载单片段保留；删除不是简单关闭详情。

### 6.5 素材与版本页

素材：搜索、筛选、真实候选、批量加入/新建事件。可打开全量宽面板，但不得直接复用旧候选 HTML。列表与胶片带共享候选集合与选择。

版本：大缩略图、版本标识、标题、时长、片段数、真实检查状态；操作为预览、精剪、下载、保留、更多。最新版本可突出，不自动把它设成所有后续操作的目标。四版以上全部可访问。

## 07. 中央预览、时间线与胶片带

### 7.1 项目工具栏

左侧任务名与下拉；中间/次行紧凑源片或版本选择；右侧按上下文显示精剪、导出、更多。工具栏只属于中央，不横贯左侧品牌和右托盘。

不展示账号圆头像、模拟菜单栏或没有实际作用的“100%”控件。预览缩放能力确实存在时才显示缩放，且含义明确为预览比例，不是时间线缩放。

全任务进度不在这里重复画一条大阶段流；最多显示短状态。宽度不足先收起低频动作至更多，不缩小任务名到无法阅读。

### 7.2 视频舞台与控制条

播放器独立 16px 圆角卡，舞台背景深于主板。视频 `contain` 完整显示横竖画幅，不拉伸、不默认裁切。界面不叠加参考图中的宣传语。

控制条高 48px，短高窗口 44px：圆形浅绿播放/暂停、上一/下一片段、时间码、进度、音量、倍速、显示/全屏。只保留一套控制。进度条浅绿，未播放段为低对比深面。

源视频和成片时间必须明确区分。点候选进入“源片片段预览”，提供“返回 Vxxx”并恢复该版本位置。异步加载回调必须核验当前媒体，不让旧视频 metadata 把新视频时间写坏。

当浏览器无法解码源片时，舞台内显示可理解错误；不能清空任务。代理预览仅在现有能力存在并按授权允许时启用。不要擅自把选文件变成自动转码/分析。

### 7.3 时间线视觉与默认轨道

时间线是一条紧凑、可操作的胶片编辑带，不是有标题的大白色报表。

默认源片视图：画面 56—64px、音频 36—40px、事件轨在分析有结果后显示。成片视图：视频、音频、真实字幕（存在时）。人物/说话人轨按当前审核任务展开；切点、关系线、AI 提案通过图层菜单显示。无字幕不画假字幕，无音乐功能不画 Music。

常规 244px 时间线可分为：工具栏36、总览16、标尺22、画面64、音频40、事件/字幕42、底部24。短高 172px 保留工具栏28、标尺20、可滚动轨道区104、底部20，总览收为工具菜单入口。不要让增加轨道改变中央整体构图。

左轨道名固定 88px，短高/窄中央可 76px。缩略图保持比例，连续帧间距 2px。画面与波形来自当前素材，不使用静态假波形充当分析结果。

播放头是 1—2px 浅绿垂线和小手柄；选区为浅绿边与深绿半透明底；字幕轨偏深绿蓝但不鲜蓝或紫。状态不同必须有文字/形状辅助，不能只用颜色区分。

### 7.4 时间线操作与数据边界

点击标尺定位；点击事件/镜头定位并打开详情；拖动播放头不创建编辑历史；拖动边界释放时形成一次修改；Esc 取消临时修改。源片分析轨不接受没有业务意义的拖拽重排；成片精剪轨可按原能力重排、分割与调整。

保留缩放、全览、回到播放头、缩放当前事件、波形/关键帧切换、手动选区、入出点输入、预览、前后移动/排序、取消、确认、确认后合成等能力。前移/后移需明确原业务含义，不以模糊箭头替代。

时间单位沿用真实媒体与服务契约，在适配边界统一即可；不为本次视觉重建强制重写所有时间数据类型。必须有明确的源片/成片坐标域与边界校验。精确逐帧能力以实际引擎为准，不把普通浏览器 seek 宣称为帧精度保证。

### 7.5 底部 ContextFilmstrip 必须恢复

中央底部固定一条横向胶片带，默认 76/68/56px，随高度条件变化。它是已有内容的紧凑导航投影，不是新建独立素材库。

源片/审核状态显示当前源素材或候选缩略图；版本状态显示当前版本的片段顺序；精剪状态显示可插入的现有片段。标题或工具提示明确当前展示的集合。内容少时左对齐，不拉伸一张图铺满。

缩略图以真实 16:9 或素材比例展示，约 80—96px 宽；当前预览用浅绿描边。首位“添加/更换素材”仅在原能力允许时出现；没有多素材能力时明确为更换视频，不制造伪多素材入口。末尾“展开素材”打开右托盘素材页。

点击定位、不自动勾选；拖动加入只在对应精剪能力存在时启用。胶片带与右侧素材页不维护第二套 selection。该带恢复的是原型的媒体密度和操作节奏，不替代上方真实时间线。

## 08. 左侧对话、计划与确认

输入框始终固定。常驻工具是素材、上下文引用、Skill/执行菜单、发送；优化指令、更多设置放菜单。草稿态允许输入与模式卡两种开始方式，不能要求用户先点模式才能聊天。

上下文引用显示任务、媒体/版本与时间范围，保存结构化引用而非仅文本。切换播放器不偷偷修改已引用对象。输入中保留中文组词处理，空白不发送，Shift+Enter 换行；失败可重试且不重复发起业务任务。

助理头像只在轮次开头出现；四个工具运行不生成四个大机器人卡。运行摘要显示“正在读字幕 / 正在整理候选”等实际步骤，日志进入活动页。用户正在阅读旧消息时不强制滚到底部。

计划状态包括：生成中、待澄清、待确认、运行、待审核、失败、停止中、已停止。待确认显示目标、范围、输出形式和执行方式；“确认并开始”是显式操作。修改计划使旧确认失效；自动执行到审核样片也必须先确认计划。

计划详情属于左侧上下文路由或用户主动打开的宽面板，不自动弹出遮挡视频。每步先显示目的与输出，模型与参数折叠。保留修改、停止、失败链路重试、封面审核、打开样片等现有动作，但随阶段出现。

上传完成、生成计划、执行分析是三种状态。输入前不分析、不渲染；生成计划时未读取媒体内容就不得显示“视频分析中”。

## 09. 四类审核的完整落点

### 9.1 高光

事件是一级对象，源镜头是二级对象。结果概览以事件卡呈现，展开/列表页检查内部镜头。支持事件选择、半选状态、删/替/加镜头、候选中勾选并新建事件、AI 推荐事件与人工选择。

生成设置保留合成一条/分别导出、目标时长（仅用户指定时作为约束）、版本数量、字幕方式和样式；输出编码与分辨率策略遵守现有能力。不要从原型推导固定 60 秒或固定三版。

### 9.2 内容探索

查询与结果集选择在托盘顶部；片段为主体；诊断进入“检索详情”。保留匹配理由、证据、转写、画面人物、说话人、屏幕文字、边界编辑与下载。

完整问答、仅问题、仅回答、拆分问答四种模式只在有真实结构时启用。支持源时间、自定义、LLM 推荐排序，推荐排序先审核。清单跨历史查询保留来源范围与人工边界；新查询不能清空旧结果与已保留清单。加入清单不等于立即编码。

检索不完整要说明未覆盖范围，不能写“已找到全部”。全选是当前页或当前筛选必须明确，不能将未知未加载内容静默全选。

### 9.3 人物

托盘内部“校正分组 / 选择目标”两步，使用真实代表帧、匿名编号或用户命名。保留合并、将所选片段拆为新人、撤销、完整出镜片段列表、任一人物/同时出现匹配以及只保留正在说话的交叉条件。

校正选择与提取目标分离。人物轨和人物列表共用状态，点击预览不自动勾选。“人物正在说话”必须有真实关联证据，不能仅凭画面有此人且同时有声音就认定。

### 9.4 说话人

保留自动或 1—12 人设置、开始识别、试听、分组合并、发言归属移动、新说话人、播放点拆分、撤销，以及包含文本筛选。发言保留所选、排除所选、保留回答及前置问题三种范围完整呈现。

临时跨视频查找在更多中进入独立流程，显示参考声音、目标视频、会话范围、开始/取消、结果；不新增永久声纹库或跨项目默认身份绑定。没有真实接口能力不能以假按钮占位。

对象、轨道和人工修正共享结果修订。旧分析晚返回不覆盖刚完成的校正。声音试听停止其他音频，避免多处同时播放。

## 10. 精剪、字幕、封面与导出

### 10.1 精剪不是保留旧弹窗换色

复用编辑命令与渲染引擎，重建 `FineEditView` 的界面结构，使用同一主板与托盘。中央播放器/时间线保持位置；右托盘变成“片段 / 字幕 / AI 修改 / 导出”属性路由；左栏“助理 / 素材”切换，不永久删除对话。普通工作台退出精剪后恢复原版本与位置。

保留：素材搜索、模式素材/源片范围、推荐/时间线/已保留/其他筛选、插入位置、跟随播放头、自定义范围、文本新增/删除、字幕拖动、片段拖拽排序、边界调整、多选、切分、裁左/右、复制、标记、吸附、逐帧、缩放、撤销/重做。

属性按时间、速度与转场、声音分组；保留音量、静音、淡入淡出和声音衔接。参数必须来自实际引擎的允许范围。保存与取消明确，连续拖拽只产生一个历史动作。

AI 修改为可审核提案：展示对象、动作、前后变化、基准修订与不能执行项。用户编辑后旧提案过期，不能强行应用覆盖新草稿。

### 10.2 字幕

专门的宽校对视图：左预览与样式，右逐条 cue，底部固定保存/确认。保留安全区、字号/位置、自然语言样式命令、时间文本、拆分/合并/删除、AI 校对建议、接受/保留、低风险批量接受。

源片已有字幕时，叠加风险与用户确认不能折叠隐藏。AI 校对只是建议，不是自动覆盖。文字、时间、位置、样式或剪辑顺序/速度改变后，相关最终确认失效；正式烧录前重新校验。

### 10.3 封面与片头

从版本或计划进入封面轨/编辑页面，保留候选、编辑、选择、保存、下载。保存封面图不会生成视频。只有“生成封面片头版”才进入时长与编码确认，默认片头时长沿用现有能力并显示真实值。

封面与视频版本关联明确，不能给 V002 选封面却覆盖 V001。时间线上封面选择标记与有时长的片头段必须可区分。

### 10.4 版本与导出

已有文件“下载”不自动重新编码；“生成高清新版本”“生成封面片头版”是新编码任务。保留 MP4、样片、高清、SRT、JPG、发布包及成片库保存入口。

预检检查有效片段、素材可用、边界、所需字幕确认、片头确认与真实质量状态。不能增加无关阻塞，例如纯视频下载却强制先选封面。

提交导出绑定完整不可变输入快照或已有不可变草稿修订，保留速度、转场、音频、文本、字幕与封面数据。用户继续编辑不改变正在导出的输入。新导出不覆盖旧版本；执行中禁用重复动作并关联现有任务，响应丢失时先核对任务再重试。

## 11. 首页、任务、成片库与管理页

首页沿用暖米画布＋深色主板，品牌尺度与工作台一致。创建任务是主入口，最近任务为真实列表，不建额外三张指标大卡。选择媒体后进入新工作台草稿，不先跳回旧上传表单页。

上传保留点击/拖放、本地预览、更换、MP4/MOV/MKV/WebM/M4V/AVI 与真实校验；限制从服务读取，不编造容量上限。未知上传进度不伪造百分比。现有不支持续传则明确重新上传，不假装恢复。

任务抽屉保留搜索、全部/进行中/待确认筛选、加载更多、打开、允许状态下删除及确认。删除任务是否连带输出必须核对后端，不自行假定。切换任务处理未保存编辑但不丢当前任务运行记录。

成片库保留预览、搜索、排序、来源任务、日期/大小/时长、下载、删除。区分“空库”“搜索无匹配”“读取失败”。返回恢复工作台上下文。

设置使用新独立管理页，不把密集表单挤进窄托盘。完整保留视觉分析、剪辑规划复用/独立、Agent 模型、运行环境、服务连接、Key 显隐、地址、模型列表与手填、思考/JSON 配置、探测和保存。连接成功不等于已保存；未保存变更需处理。

Skills 保留草稿生成、模拟规划、标准 ZIP 安装、列表、审核启用/禁用。Plugins 保留检查 ZIP、来源版本、工具、权限警告、主动信任后启用，不默认勾选。令牌仅按现有会话规则存储，不进 URL、日志和截图。

浏览器前进/后退与现有路由语义一致；管理页离开时停止无关预览音频，不销毁当前任务数据。

## 12. 状态、保存、错误与可访问交互

### 12.1 视图和业务必须分离

建议以任务、结果集、选择、媒体、编辑草稿、计划、导出与布局为分离状态域。是否使用现有状态库由工程决定，不要求全项目另建第二套 store。

结果选择按 task/resultSet 隔离；focused/playing 与 checked 分离；源片与成片位置分离；草稿 dirty/save 状态与计划状态分离；布局折叠不触发业务状态迁移。

异步请求关联任务与请求 ID，计划/结果/草稿关联真实修订。晚返回更新对应历史，不抢占当前视图。断线显示待同步，不冒称任务失败或已停止；重连读取真实状态。

### 12.2 状态样式

| 状态 | 展示位置与反馈 | 禁止 |
|---|---|---|
| 无素材 | 中央上传面＋左侧简短引导 | 全页面堆步骤卡 |
| 素材就绪 | 中央真实预览、右四模式 | 自动分析或显示成功结果 |
| 计划中 | 左侧一条步骤摘要 | orb、阶段流、百分比同时重复 |
| 待确认 | 计划摘要与明确确认 | 将输入按钮默认为已授权执行 |
| 运行中 | 当前步骤、实际进度、停止 | 假 ETA、无依据百分比 |
| 部分成功 | 保留已有内容，说明缺失部分 | 清空结果后笼统报错 |
| 待审核 | 右侧真实概览、选择与生成 | 用户操作中强行跳标签 |
| 停止中 | 等待服务确认 | 立即宣称已取消全部任务 |
| 失败 | 就地原因、保留内容、下一步 | 只闪一下 Toast 或泄露技术密钥 |
| 已生成 | 明确版本、预览/导出 | 固定“质量通过”与“三个版本” |

### 12.3 弹窗与键盘

界面模态层共用 OverlayHost。打开焦点进入合理控件，关闭返回触发按钮；Esc 只关闭最内层，不一次关闭所有编辑。破坏性操作显示影响对象，提供明确返回；普通导航不反复弹确认。

核心操作键盘可达，输入有可见标签，错误关联字段，颜色不是唯一状态标记。正文对比度以 4.5:1 为项目验收目标，关键非文本控件以 3:1 为目标；必须在实际组合上测量，这些目标不表示现已测过。

控件悬停约 120ms，面板过渡约 180ms；播放器、拖拽与播放头无缓动延迟。减少动态效果时关闭非必要动画。拖拽不能是唯一操作方式，边界和排列保留输入或按钮路径。

### 12.4 保存与安全

保存状态来自真实持久化结果。本地草稿明确标注本地，不能写成已云端保存。退出时提供继续编辑、保存退出（能力可用时）、放弃未保存变更。恢复失败要说明，不静默丢失。

所有文本安全渲染，不把用户/模型文字作为 HTML 执行。插件信任、API Key、访问令牌与素材发送范围保持原有授权边界。本次 UI 不新增任何永久声音身份或隐私推断。

## 13. 业务复用方案：适配数据，不适配旧外观

### 13.1 必须先完成的源码盘点

开发从真实仓库确认：技术栈、页面入口、样式加载、旧全局选择器、静态模板、动态 HTML 函数、媒体控制、事件订阅、任务状态、结果缓存、草稿保存、编辑命令、字幕与导出接口。

输出实际文件路径和函数位置，不能照抄 S1 的 DOM 速查表当成已完成源码分析。特别检查是否有旧函数通过 `innerHTML` 向聊天/审核容器插入卡片，是否有旧初始化脚本每次轮询重建面板。

### 13.2 允许与禁止复用的边界

| 代码类别 | 处理 |
|---|---|
| API 客户端、服务鉴权、任务请求与取消 | 复用真实协议，隔离在服务层 |
| 结果数据、校正算法、时间映射、排序、编辑命令 | 可复用；保留测试和语义 |
| 媒体控制器、波形/缩略图底层计算 | 可复用；接收新元素引用，不依赖旧页面树 |
| 与品牌一致、无全局副作用的基础图标/按钮 | 审查后复用，不强求重写 |
| 旧页面 shell、导航轨、旧侧栏/计划/结果卡 HTML | 重建，不移动整个旧节点 |
| 输出旧 HTML 的动态渲染函数 | 拆成数据转换/业务操作与新渲染组件 |
| 旧全局 CSS、为旧尺寸服务的选择器 | 不进入新页面样式依赖 |
| 全局 ID 查询与隐式 DOM 状态 | 改为显式引用/参数/状态；不可让 DOM 继续充当业务数据库 |

适配器返回数据与命令，不返回旧 HTML，也不接管新容器内部布局。不得通过“兼容 adapter”变相注入旧 DOM。

### 13.3 不强迫重写所有 ID

不以“ID 改名数量”判断重构成功。媒体或自动化测试确有需要时，可保留一个具体、唯一的 ID；前提是它不锁定旧结构、不加载旧布局样式、无重复节点，且依赖已记录。

默认使用新组件局部引用和语义化测试定位。禁止 `display:none` 隐藏整套旧工作台再套一个新工作台，也禁止先复制一组相同 ID 再靠 CSS 选择显示哪个。

### 13.4 新旧页面隔离

推荐独立新入口或路由。名字由现有工程确定，本文不伪造实际路由已存在。新入口只加载新工作台渲染和新样式；旧页面作为受控回退，不与新页面同时初始化。

若工程是单页应用且旧样式全局污染，先拆样式导入边界或隔离新根；仅添加 CSS layer 并不能在组织上替代这一步。不得连续叠加 override/fix/patch 文件来压制旧选择器。

临时兼容必须逐项记录用途、影响范围和移除阶段。工作台主结构、右侧卡片、播放器布局与时间线不得列为永久兼容例外。

## 14. 分阶段实施与停止条件

### 阶段 R0：冻结、审计、建立独立入口

保留当前可运行版本与回退方法，记录现有关键流程，盘点新旧样式与渲染依赖。准备真实授权的样本媒体；测试演示数据必须放独立 fixture，明确“演示”，与正式数据路径隔离。

交付：真实文件清单、重建/复用边界表、新入口可打开、旧流程快照。此阶段不允许宣称视觉完成。

### 阶段 R1：先交一个完整的视觉切片

实现新页面结构、三列、主板/托盘错层、品牌区、输入、播放器、时间线、胶片带、四模式卡，以及 S0/S1/S2 三种状态。可以使用标注的演示结果，但视频内容必须是实际媒体，不得把原型截图当页面背景。

首先验收 1536×1024、1440×900、1366×768。必须提交真实浏览器截图，不提供渲染效果图替代。附列宽/高度测量、实际加载 CSS、已接入/演示组件说明。

**R1 未通过，停止接入更多业务。** 不能先做完所有接口，再要求用户接受一个不像 A 版的界面。

### 阶段 R2：接入一条真实主流程

优先上传 → 输入或高光模式 → 计划生成 → 确认 → 分析 → 事件审核 → 生成版本 → 预览。接一块验证一块真实数据不会让布局崩坏或旧卡片重现。强制测试长任务名、长中文标题、无缩略图、空结果与失败。

交付：真实操作记录、同三断点截图、差异说明与修复。旧动态模板若仍被调用，不能进入下一阶段。

### 阶段 R3：接入四模式、候选、人物与说话人

完成内容历史/成片清单、校正与撤销、范围选择、证据、轨道同步和临时跨视频查找。用第 16 章能力矩阵逐项定位入口。功能多不意味着一次全部摆在主屏。

### 阶段 R4：精剪、字幕、封面、导出与管理

保留编辑与渲染引擎，重建界面，完成确认/修订/版本保护；任务、库、设置与能力管理统一外观。不能以“高级页不常用”为由打开旧界面不作说明。

### 阶段 R5：最终回归、清理与切换

通过视觉与业务双门槛后再切换正式入口。清理不再使用的旧工作台渲染、样式导入与事件订阅；保留明确的部署回滚，而非前端长期同时维护两套界面。

各阶段必须报告：改动文件、实际复用函数、新渲染组件、截图、通过/失败/未执行测试、剩余兼容项。代码或文档静态检查不等于真实浏览器功能验收。

## 15. 视觉验收方法与硬门槛

### 15.1 验收不是“配色差不多”

使用同一任务内容、视口、缩放、字体加载状态和默认布局进行比较。基准图有演示媒体与装饰，与真实产品内容不一致，因此不将整图像素相似率当唯一分数；应先验收结构锚点，再验收组件外形和内容密度。

R1 后经确认的真实浏览器截图成为产品视觉回归基线。后续与该基线做相同测试数据的截图差异检查，不反复用生成图里的细节强迫产品显示假状态。

### 15.2 必须全部通过的项目

| 编号 | 检查点 | 不通过的例子 |
|---|---|---|
| V01 | 暖米外底＋深色主板＋独立右托盘清楚可见 | 整页还是旧蓝黑背景，只换按钮绿 |
| V02 | 1280 及以上默认完整三列 | 1366 自动藏右栏，回到旧双栏 |
| V03 | 左品牌约 32px 字标与宽新建按钮 | 挤成工具栏小 Logo |
| V04 | 右托盘顶部下沉、底部齐主板 | 所有列顶部一条横线，一根 header 贯穿 |
| V05 | 草稿态四模式为真实大面积柔色卡 | 深色表单＋四个小彩色标签 |
| V06 | 结果概览图像优先，列表为深入视图 | 直接把旧结果 HTML 丢进托盘 |
| V07 | 中央视觉顺序完整：工具栏/预览/时间线/胶片带 | 底部带消失、重复结果堆在视频下 |
| V08 | 输入始终可见，左栏独立滚动 | 消息多后输入被推到页面底下 |
| V09 | 浅绿播放、选区、按钮体系 | 混入旧橙播放头、紫轨和霓虹青 |

| V13 | 视频内容、波形、字幕、版本数来自实际数据或标记演示 | 正式页固定人像、三版本、质量通过 |

| V15 | 没有用原型整图/图片按钮模拟界面 | 看起来像，但真实操作没有组件 |

任一 V 项失败，不能以总分平均、功能通过或“已完成 90%”抵消。

### 15.3 测量目标

默认外边距、列宽、工具栏/胶片带/时间线高度与第 3 章表值允许约 ±4 CSS px 实现偏差；由滚动条等平台因素导致的偏差须记录。主板和托盘的锚点、角色与错层不允许改变。

卡片内部尺寸可在规定范围内适应文案；标题超过两行进入详情，不能撑破整体卡型。发生少结果、无图片等状态时允许内容减少，不强制与样本填满同样面积。

正常截图不能有页面级横向溢出、截断的输入/主动作、重叠工具条、靠更小字体维持布局或一整块缺少功能的空白。视频原比例留白、右托盘顶部偏移是有定义的留白，不应被当作“缺陷”再填满。

### 15.4 工程验收证据

必须提供：新页面入口、组件树、新页面实际加载的样式文件、旧动态渲染依赖处理表、浏览器截图、关键尺寸与失败项。仅展示一份新的 CSS 文件或 DOM 挪动清单，不证明界面层已经重建。

详细执行表见 `视觉与业务验收清单.md`。未执行测试一律标记未执行，不以本文规格存在为通过。
