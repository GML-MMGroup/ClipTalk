# 二次精剪简化改版

2026-09-09。保留深绿色风格，以大预览和轻量时间线为主。

- 默认收起素材和属性面板，预览高度比例调整为 58%；同时最多打开一个面板，小屏使用抽屉。
- 常驻添加片段、分割、删除、字幕和缩放；逐帧、吸附、裁左裁右、复制、标记和文本放入“更多”。
- 片段只展示缩略图、标题和时长。空字幕与文本轨隐藏，属性中仅常驻时间、速度和音量，其他参数放入“高级”。
- 缩短保存、预览、字幕和 AI 提案文案；主操作统一使用浅绿色。清理 theme.css 中对精剪区域的重复覆盖，由 secondary-editor-focus.css 管理精剪外观。
- 导出前要求预览与当前修订一致，预览过期时提供生成入口；关闭字幕时不再烧录残留草稿。
- 保存失败保持明确状态；关闭或切换精剪草稿后忽略迟到保存结果。进入精剪定位到首段真实入点，重新打开时恢复视频地址。
- 保留原编辑、字幕、预览、导出接口及持久化草稿；布局偏好使用 v2 键，旧双侧栏配置不再自动恢复。

## 验证

前端全量 140 项通过；编辑相关 Python 44 项通过；ESLint、Python 静态检查及前端归属检查通过。新增浏览器回归覆盖四种宽度、空轨隐藏、面板互斥、过期预览、禁用字幕以及迟到保存和错误恢复。

在独立测试实例中使用真实视频，经界面裁剪、关闭字幕、保存，首次导出正确提示先更新预览；预览完成后确认导出，生成新版本。实际下载 HTTP 200，708955 字节，ffprobe 验证时长 7 秒、640×360、含音轨。没有改动原服务的任务。
