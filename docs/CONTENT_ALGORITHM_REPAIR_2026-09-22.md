# 内容剪辑算法修复记录

## 问题与处理

- 要求解析与格式修复：对有原文来源的并列条件检查遗漏，修复前后的条件也需要保留；更新解析缓存版本。不把“格式合法”当作“要求完整”。这是来源一致性校验，不是完整的自然语言语义证明。
- 完整片段边界：完整语义片段不能裁掉用于支持该事件的首尾证据；发现此问题时在原窗口内重试一次，仍不成立则待核验，不无限重试。
- 单画面候选：未审核的单帧命中不直接当作两秒剪辑段，先在受素材范围限制的局部窗口内核验完整事件。已确认或手动调整的范围不自动扩展。
- 用户勾选：只记录选用意愿，不再把保留/全选转换为内容与边界核验通过。明确手动设置边界仍保留独立的人工覆盖记录。
- 已核验要求：保留每段真正支持的条件和边界证据，用于多目标覆盖检查；同一段支持多个要求时不会重复加入选择。
- 编排失败：模型异常、降级草稿或不安全提案不能自动变成简单拼接的“成功方案”；保留草稿并报告失败，重试会重新调用规划器。
- 质检修复：用户触发重试时，内容问题回到检索、时长问题回到编排、画幅问题回到画幅生成、纯不确定问题只重跑质检。缺少步骤或冻结范围不允许扩大时不提供自动修复承诺。保留最近五次修复前报告。
- 更新边界核验版本，旧证据需要重新核验；不会修改旧视频文件。
